# Ручная установка IPK

Для ASUSWRT-Merlin с готовой Entware. Вы скачиваете пакет на компьютер,
переносите его на роутер и запускаете установку по SSH.
Файл можно передать через WinSCP/SCP или скопировать на флешку по Samba обычным Проводником.

## 1. Выбрать пакет

В SSH роутера проверьте архитектуру:

```sh
/opt/bin/opkg print-architecture
```

| Архитектура Entware | Пакет |
|---|---|
| `armv7-2.6` / `armv7-3.2` | ARMv7 |
| `aarch64-3.10` | AArch64 |

Скачайте подходящий IPK и `SHA256SUMS` из [актуального выпуска](https://github.com/madworldpay/nfqws2-asus-community/releases/latest).
Проверьте скачанный файл на компьютере: в Windows PowerShell —
`Get-FileHash .\имя-файла.ipk -Algorithm SHA256`, в Linux — `sha256sum имя-файла.ipk`.
Вместо `имя-файла.ipk` укажите название скачанного IPK.
Сравните результат со строкой этого файла в `SHA256SUMS`.

Для следующих шагов скопированный пакет будем называть `nfqws2-asus.ipk`.
Переименовать его можно при переносе; архитектуру пакета выбирайте до этого.

## 2. Передать на роутер

Выберите **один** из способов ниже. Подготовьте папку на накопителе Entware
командой **в SSH роутера**:

```sh
mkdir -p /opt/tmp
```

### Через WinSCP

1. Откройте WinSCP на компьютере. Выберите протокол **SCP** для штатного SSH ASUS.
2. Введите локальный IP роутера, его SSH-порт и ту же учётную запись, с которой входите по SSH.
   В примерах ниже это `192.168.1.1`, порт `22` и пользователь `admin`; подставьте свои значения.
3. В правой панели откройте `/opt/tmp`, в левой — папку со скачанным IPK.
4. Перетащите проверенный файл вправо и назовите копию `nfqws2-asus.ipk`.

Итоговый путь на роутере: `/opt/tmp/nfqws2-asus.ipk`.

### Командой SCP с компьютера

В PowerShell или терминале **компьютера**, где лежит пакет:

```sh
scp -O "./package.ipk" admin@192.168.1.1:/opt/tmp/nfqws2-asus.ipk
```

Замените `./package.ipk` путём к скачанному файлу, а адрес и логин — своими.
Для SSH на другом порту добавьте, например, `-P 2222` перед путём к файлу.
В современных клиентах OpenSSH параметр `-O` выбирает SCP вместо SFTP,
которого может не быть в штатном SSH ASUS.

### Через флешку и Samba: обычным Проводником

Если Entware находится на USB-накопителе, **флешка остаётся в роутере**.
Её папку можно открыть на компьютере как сетевой диск и скопировать туда IPK.

1. В веб-интерфейсе ASUS откройте **USB-приложения → Серверный центр → Samba / Сетевое окружение**.
   Названия пунктов зависят от прошивки. Включите общий доступ к нужной папке USB-накопителя
   и дайте своей учётной записи право чтения и записи.
2. Подключитесь с компьютера к домашней сети роутера.
   В Windows нажмите **Win + E** и введите в адресную строку Проводника, например,
   `\\192.168.1.1\USB`. Это сетевой путь, без `http://`.
   Введите данные учётной записи Samba, если появится запрос.
3. При желании выберите **«Подключить сетевой диск»** в разделе «Этот компьютер»:
   эта же папка появится под буквой диска. Можно и просто работать с сетевой папкой.
4. Создайте в ней папку `nfqws2-update` и скопируйте проверенный пакет как
   `nfqws2-asus.ipk` — обычным копированием и вставкой.

На других ОС это тоже обычная сетевая папка:

| ОС | Как открыть |
| --- | --- |
| Windows | Проводник: `\\192.168.1.1\USB` |
| Linux | Файловый менеджер, **Ctrl + L**: `smb://192.168.1.1/USB` |
| macOS | Finder → **Переход → Подключение к серверу**: `smb://192.168.1.1/USB` |

**Сетевой путь компьютера и путь в SSH отличаются.** В примере общая папка `USB`
открывает корень раздела, смонтированного на ASUS в `/tmp/mnt/USB`:

| Где смотрите | Путь к одному и тому же файлу |
| --- | --- |
| В Проводнике Windows | `\\192.168.1.1\USB\nfqws2-update\nfqws2-asus.ipk` |
| В SSH роутера | `/tmp/mnt/USB/nfqws2-update/nfqws2-asus.ipk` |

Имя общей папки и точка монтирования могут отличаться от примера.
В SSH команда `ls /tmp/mnt` покажет имена смонтированных накопителей;
сопоставьте их с папкой, которую открыли через Samba.

Для примера выше скопируйте пакет в подготовленную папку Entware — **в SSH роутера**:

```sh
cp "/tmp/mnt/USB/nfqws2-update/nfqws2-asus.ipk" /opt/tmp/nfqws2-asus.ipk
```

Сначала замените `USB` и путь к папке, если у вас они другие.
При копировании через Samba установка сама не начинается.
[Настройка Samba в документации ASUS](https://www.asus.com/global/support/faq/1011279/).

## 3. Установить

В SSH роутера для **первой установки** выполните:

```sh
/opt/bin/opkg update
NFQWS_ASUS_NO_START=1 /opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Обработка останется выключенной до настройки. Эта же команда подходит для
обновления, если службу нужно оставить выключенной.

Для обновления **с запуском NFQWS2 после установки** используйте:

```sh
/opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Обычный `opkg install` пытается запустить службу после установки. Если хотите
автоматически сохранить её прежнее состояние, используйте в панели
**«Обновление» → «Подготовить пакет» → «Установить обновление»**.
Зависимости загружаются из Entware. При ошибке сохраните вывод установки для диагностики.

## 4. Открыть панель

Откройте `http://IP-роутера:90`.

**Вход в панель ASUS:** используйте логин и пароль администратора роутера.
Если панель не может прочитать системные учётные данные ASUS, автоматически
включается резервный вход: **логин `root`, пароль `asus`**.
Ранее заданный отдельный пароль панели сохраняется при обновлении — используйте его.
Кнопка **«Сменить пароль»** позволяет задать свой пароль панели.

Выполните подсказки проверки ARK, выберите устройства и стратегию, сохраните настройки
и запустите NFQWS2. Если нужен SmartDNS, подключите его через отдельный мастер и подтвердите DNS.

Для OpenWrt используется нативный пакет: [ручной выбор и установка](OPENWRT.md#установить-пакет-вручную).
