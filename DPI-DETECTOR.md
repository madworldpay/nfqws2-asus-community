# DPI Detector

**Интерфейс Build 99.** Оригинальный терминал доступен с Build 88, скачивание TXT и защищённое удаление — с Build 91, отдельная «Проверка сервисов» — с Build 96. Кнопка «DPI Detector» открывает окно прямо в панели. [Запуск через SSH](#запуск-через-ssh) также доступен.

DPI Detector — отдельный необязательный инструмент [Runnin4ik](https://github.com/Runnin4ik/dpi-detector). Он помогает сравнивать DNS, HTTP, TLS, QUIC и соединения с сетевыми целями. Для работы NFQWS2 установка Detector не нужна. Detector не подбирает и не меняет стратегию автоматически.

[Меню Detector и выбор DNS на реальных снимках Build 99](SCREENSHOTS.md#build99-detector) · [крупные скрины сравнения стратегий](docs/DETECTOR-COMPARISON.md).

## Запуск из панели

1. Нажмите **«DPI Detector»** в верхней части панели. Если он ещё не установлен, нажмите **«Установить DPI Detector»** и подтвердите. Панель проверяет закреплённый файл, SHA256 и запуск. После установки открывается оригинальное меню; отдельный вход по SSH не нужен.
2. Начните с выбранных по умолчанию тестов **1, 2, 3**. Стрелки перемещают выбор, **Пробел** отмечает тесты, **Enter** подтверждает. На телефоне используйте кнопки под терминалом.
3. Дождитесь результата и нажмите **S** в меню результатов, чтобы сохранить оригинальный TXT.
4. В окне Detector обновите список **«Отчёты TXT»** и нажмите кнопку скачивания рядом с нужным TXT — файл сохранится на ваш ПК или телефон. Для отправки через предпросмотр также доступен **«Экспорт / поделиться»**.

Кнопка **«?»** и раскрываемая справка в окне объясняют установку, тесты, управление и чтение отчёта. **Esc** возвращает назад в оригинальном меню, **Q** завершает Detector. Закрытие окна панели останавливает принадлежащий ему терминал и текущие тесты. Для нового запуска откройте окно снова. Окно содержит один оригинальный терминал: обновление состояния, списка отчётов или справки не создаёт его копий. «Открыть терминал снова» заменяет его сессию. Второй терминал или отдельная проверка Detector одновременно не запускаются.

Историю прокручивают колёсиком или вертикальным жестом; рядом есть кнопки начала, конца и страниц. На клавиатуре работают **Shift+PageUp/PageDown** и **Shift+Home/End**. Широкие таблицы прокручиваются горизонтально отдельно от страницы.

## Сравнение и чтение отчёта

[Разобранный пример: штатная стратегия и личная DOM.RU](docs/DETECTOR-COMPARISON.md) — что сравнивать, как импортировать профиль и почему результат одной линии не переносится на всех.

**Detector важен для проверки результата после импорта:** он позволяет сравнить стратегии по одинаковым тестам и отделить проблемы DNS от отказов соединения, TLS или QUIC. Для исходного сравнения сохраните результат с выключенным NFQWS2, затем включите его и повторите те же тесты. При сравнении двух стратегий проверяйте каждую с включённой службой в одинаковых условиях. Меняйте по одному параметру. Учитывайте DNS, VPN, другой обход на пути и изменение адресов целей: иначе разницу нельзя уверенно приписать стратегии.

- **DNS:** ошибки обычного или зашифрованного DNS, изменённые ответы и неожиданный резолвер помогают найти причину сбоя. Такой отчёт не доказывает отсутствие всех DNS-утечек.
- **Соединение:** тайм-аут до установления TCP, отказ TLS и обрыв передачи данных — разные результаты. Один отказ сам по себе не доказывает блокировку провайдером.
- **Протокол:** HTTP, TLS и QUIC проверяются отдельно. `—` у QUIC может означать отсутствие поддержки у сервера; `CLOSED` — закрытое сервером рукопожатие.
- **Процент OK:** относится только к выбранным тестам. Он не гарантирует работу всех сайтов, видео, перемотки и голосовых звонков.

**Что означает OK:** оригинальный Detector оценивает прохождение своей сетевой проверки. Завершившийся HTTP-ответ с ошибкой сервера, например **400**, тоже может получить OK. Это не подтверждение, что открылась рабочая страница, загрузились её ресурсы или выполнен вход. Обычный редирект также не доказывает доступность конечной страницы.

DNS-доступность в оригинальном меню — **независимая проверка его списка публичных DNS-серверов**. Она не проверяет всю настроенную цепочку SmartDNS или AdGuard Home. Одинаковый итог этого теста после смены профиля DNS сам по себе не означает, что профиль не применился.

Проверьте нужный сервис с выбранного устройства после изменения стратегии. **«Собрать диагностику»** собирает сведения о роутере и не запускает сетевые тесты Detector.

## Проверка сервисов

Начиная с Build 96, в окне Detector доступен отдельный режим **«Проверка сервисов»** для Facebook, YouTube и Discord. Он дополняет оригинальное меню: показывает HTTP-код, перенаправление, объём прочитанного ответа и сетевую ошибку по фиксированным контрольным доменам. Переключение закрывает принадлежащий окну оригинальный терминал; параллельные проверки не запускаются.

Начиная с Build 97 выберите **«Локальный DNS роутера»** (`127.0.0.1:53`, включая SmartDNS при его подключении) или **«Системный DNS»**. Выбор действует только на эти контрольные запросы и указан в TXT; он не меняет настройки роутера и независимые DNS-тесты оригинального Detector. Ошибка DNS показывается отдельно, без скрытого перехода к другому резолверу.

Выберите сервис и нажмите **«Запустить проверку сервиса»**. За один запуск последовательно проверяются три URL выбранного сервиса; всего закреплено девять целей:

| Сервис | Контрольные URL |
| --- | --- |
| Facebook | `https://www.facebook.com/`, `https://m.facebook.com/`, `https://static.xx.fbcdn.net/` |
| YouTube | `https://www.youtube.com/`, `https://i.ytimg.com/`, `https://www.gstatic.com/` |
| Discord | `https://discord.com/`, `https://cdn.discordapp.com/`, `https://gateway.discord.gg/` |

Проверка выполняет HTTPS-запросы с проверкой сертификатов, использует выбранный путь DNS и не переходит по редиректам. HTTP 400 показывается как ответ ошибки сервера. Обрыв соединения и ответ HTTP 403/404 — разные результаты: у корня CDN может не быть публичной страницы. На один запрос отводится до 10 секунд, чтение тела ограничено 256 КиБ и отмечается как частичное при достижении предела; контрольные домены не охватывают все ресурсы сайта, воспроизведение видео, голос, матч или авторизацию. Полная работоспособность сервиса автоматически не заявляется.

**«Скачать TXT проверки сервиса»** сохраняет контрольный отчёт на ваш ПК или телефон. Для каждого запроса записаны время и снимки состояния NFQWS2, режима и SHA256 конфигурации до и после него. Если известные значения различаются, отчёт отмечает изменение; неполные данные помечаются неизвестными. Совпадение двух снимков не исключает изменений между ними. При переводе часов роутера назад сохраняются исходные отметки и предупреждение; длительность измеряется монотонным таймером. Это контекст именно контрольных запросов, а не чужого прогона оригинального меню. Настройки, списки, DNS и состояние службы проверка не меняет.

В оригинальных TXT историческое состояние NFQWS2, режим и SHA256 конфигурации не записаны этой интеграцией и остаются неизвестными. Панель не подставляет в них текущее состояние службы и не определяет начало теста по времени открытия терминала. Для сравнения исходных TXT сохраняйте условия каждого прогона отдельно.

## Отчёты и удаление

Оригинальный TXT остаётся локальным и может содержать сведения о сети. Для отправки формируется отдельный очищенный JSON с распознанными показателями; он может быть частичным. Отправка требует предпросмотра и отдельного нажатия, тесты повторно не запускаются.

Действие **«Удалить DPI Detector»** находится в меню **«Ещё»** его окна и открывает отдельное подтверждение. **«Удалить сохранённые отчёты Detector»** по умолчанию выключено: обычное удаление сохраняет отчёты. При отдельном выборе этой галочки сохранённые отчёты удаляются без восстановления из панели. Отмена подтверждения не перезапускает текущий терминал.

## Архитектуры

Общий интерфейс предназначен для ASUS/Entware и нативного OpenWrt. Наличие пакета NFQWS2 для архитектуры не означает наличие совместимого Detector.

| Семейство | Закреплённый вариант Detector |
| --- | --- |
| ARM64, MIPS, MIPSel, x86-64; ASUS/Entware `armv7-3.2` | Официальный файл v5.0.0-alpha.21 |
| Старый Entware `armv7-2.6` и нативный OpenWrt ARM | Совместимая ARMv5TE-сборка тех же исходников; обычный официальный ARMv7-файл не запускался на испытанном старом RT-AC87U |
| x86 32-bit, MIPS64 | Совместимый файл не закреплён; установка Detector недоступна |

Это ограничение Detector, а не запрет NFQWS2 или SmartDNS. Поддержка файла и проверка запуска не заменяют сетевые испытания на каждой модели.

## Запуск через SSH

Оригинальное меню также можно открыть на роутере после установки Detector:

```sh
# ASUS / Entware
/opt/bin/nfqws2-dpi

# OpenWrt
/usr/bin/nfqws2-dpi
```

Не запускайте его одновременно с окном Detector в панели. Для сохранения TXT нажмите **S**, затем обновите список результатов в панели.
