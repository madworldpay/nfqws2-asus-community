# Обновление

## Через панель

Начиная с Build 64, панель проверяет публичные выпуски GitHub автоматически.
Нажмите **«Проверить обновления»**. Если есть подходящий выпуск:

1. **«Подготовить пакет»** — скачать, проверить подпись, совместимость и место,
   сохранить снимок настроек.
2. **«Установить обновление»** — заменить пакет и дождаться результата.

Панель может временно отключиться. Закрытие вкладки не отменяет установку.
Обновлятор сохраняет настройки, списки, данные входа и прежнее намерение запуска службы.
Прошивка, ARK и маршруты этим действием не настраиваются; перезагрузка не требуется.

Ранее подтверждённый SmartDNS восстанавливается с сохранённым профилем.
Проверьте статус после обновления. Если восстановление не завершено, остаётся
штатный DNS; не считайте это успешным подключением SmartDNS.

## Вручную

Скачайте IPK своей архитектуры, проверьте SHA256, передайте на роутер и выполните:

```sh
/opt/bin/opkg install /tmp/nfqws2-asus.ipk
```

Повторная установка сохраняет оставленные настройки. Build 65 также восстанавливает
отсутствующий обязательный конфиг из текущего шаблона пакета. При существующем
конфиге намеренно удалённые списки не возвращаются.
Не используйте force и не устанавливайте старый пакет поверх нового без разбора причины.
После установки проверьте версию, состояние службы и SmartDNS.

## Переход с Build 62 и старее

Один раз установите актуальный IPK вручную: старый обновлятор использовал частный
канал. Следующие версии доступны кнопкой без токена и учётной записи GitHub.

Панель проверяет подпись выпуска закреплённым ключом, затем размер и SHA256 пакета.
При ошибке проверки установка не начинается. Существующий частный канал, если
он задан оператором, продолжает использоваться.

Опубликованный номер Build не переиспользуется для другого содержимого.
Автоматического отката версии пакета нет. [Загрузки](DOWNLOADS.md) · [Удаление](INSTALL.md).
