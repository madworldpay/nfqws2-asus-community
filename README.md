# NFQWS2 ASUS Community

NFQWS2 с веб-панелью для ASUS и Entware: настройка стратегий, DNS для отдельных
сайтов, диагностика и обмен готовыми профилями.

**RU / EN · две архитектуры Entware**

Проверено на **GT-BE19000AI** и **RT-AC87U**. [Условия проверок и другие устройства](COMPATIBILITY.md).

## Быстрый старт

Для готовой Entware: войдите по SSH **в роутер** и вставьте одну команду.

```sh
( nfqws_url=https://raw.githubusercontent.com/madworldpay/nfqws2-asus-community/main/install.sh; nfqws_file=$(mktemp) && trap 'rm -f "$nfqws_file"' 0 && { curl -fL --connect-timeout 10 --max-time 60 "$nfqws_url" -o "$nfqws_file" || wget --https-only -T 20 -t 2 -O "$nfqws_file" "$nfqws_url"; } && sh "$nfqws_file" )
```

Установщик выберет актуальный IPK и проверит SHA256. При обновлении сохраняются
настройки и состояние службы; при первой установке обработка остаётся выключенной
до настройки. [Ручная установка IPK](MANUAL-INSTALL.md).

1. Откройте `http://IP-роутера:90` с данными администратора ASUS.
2. Откройте **«Проверка ARK»**. Если ARK отсутствует, подготовка не требуется — переходите дальше. Если модуль загружен, следуйте подсказкам панели.
3. Оставьте автоматический выбор WAN или укажите интерфейс, выберите устройства и стратегию. Можно импортировать свой JSON или пресет из облака. Сохраните.
4. Если профилю нужны отдельные DNS, настройте **SmartDNS**: выберите DoT/DoH для сайтов или импортируйте DNS вместе со стратегией, затем подключите их в мастере.
5. Запустите NFQWS2 и проверьте сервисы с выбранного устройства.

[Команды и порядок действий](QUICKSTART.md) · [Совместимость](COMPATIBILITY.md) · [Установка](INSTALL.md).

## Делитесь рабочими стратегиями

Получили хороший результат для YouTube, Instagram, Discord или другого сервиса —
**поделитесь профилем через «Экспорт / поделиться»**. Такие отчёты помогают улучшать стратегии
и пополнять облачный каталог для разных провайдеров и регионов.

Выберите стратегию, нужные списки/blobs и DNS, укажите провайдера и результат
проверки, затем откройте предпросмотр. **«Скачать JSON»** сохраняет копию вам,
**«Отправить»** передаёт её проекту. Участие добровольное; отправка не публикует
профиль в каталоге автоматически. [Как поделиться или сообщить об ошибке](CONTRIBUTING.md).

## Как устроены проверка и поддержка

- Перед изменением DNS мастер проверяет профиль, предлагает пробное подключение и возвращает прежний DNS без подтверждения.
- При импорте видно, что изменится. При отправке можно проверить точный состав и отредактировать копии; рабочие настройки от этого не меняются.
- Вместе с каждым выпуском опубликованы SHA256 и архив соответствующих исходников. [Происхождение компонентов](UPSTREAM.md).
- Работа сервиса проверяется с телефона или ПК: рост очереди подтверждает поступление пакетов, а видео, перемотка и голос требуют проверки самого приложения.

Если что-то не получилось, начните с [диагностики](DIAGNOSTICS.md).
Для описания воспроизводимой ошибки есть [Issues](https://github.com/madworldpay/nfqws2-asus-community/issues).
Настройки и диагностические файлы можно передать разработчику через предпросмотр в панели.
