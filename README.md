# NFQWS2 ASUS Community

NFQWS2 с веб-панелью для ASUS на Asuswrt-Merlin и Entware: стратегии, списки, выбор устройств, SmartDNS и перенос настроек из JSON.

**Готовим первый релиз.** Базовая сборка ещё не выбрана; исправления проходят проверку на двух роутерах. Файлы прежних сборок и их номера — в [загрузках](DOWNLOADS.md). Новые возможности ниже относятся к проверяемой сборке.

## С чего начать

1. Подготовьте Entware в `/opt`. Определите архитектуру: `/opt/bin/opkg print-architecture`. Для RT-AC87U используйте исправный USB-накопитель; он не добавляет ОЗУ.
2. Установите подходящий IPK по [инструкции](INSTALL.md). Откройте `http://IP-роутера:90` с данными администратора ASUS.
3. Откройте **«С чего начать»** и **«Проверка ARK»**. Подготовка нужна только при загруженном ARK; сначала сохраняется резервная копия. Для применения потребуется ручная перезагрузка.
4. Выберите устройства и стратегию либо импортируйте JSON с нужными блоками и файлами. Сохраните настройки.
5. При необходимости настройте **SmartDNS**: DNS и сайты → проверка → подключение.
6. Запустите или перезапустите NFQWS2. Проверьте новые соединения и нужные сервисы с выбранного устройства.

Этапы в панели показывают, что готово и что выполнено частично. Запущенный процесс и рост очереди сами по себе не подтверждают работу сайта, видео или голоса.

## Зачем SmartDNS

Он позволяет назначать отдельный DNS конкретным сайтам и закреплять IP сервиса. Разные DNS могут возвращать разные адреса CDN, на которых одна стратегия ведёт себя по-разному. Поэтому сравнивайте стратегию вместе с DNS.

**«По умолчанию»** — DNS для сайтов, которым не назначен отдельный сервер. SmartDNS необязателен и не заменяет NFQWS2. [Настройка, ограничения и возврат прежнего DNS](SMARTDNS.md).

## Совместимость

Проверяем GT-BE19000AI и RT-AC87U на конкретных прошивках. ARMv7-пакет рассчитан на Entware `armv7-2.6` / `armv7-3.2`, AArch64 — на `aarch64-3.10`. MIPS не поддерживается.

Опыт RT-AC87U показал, что ограничения старого ядра иногда можно устранить отдельной доработкой. Это не обещание поддержки всех старых ASUS. [Модели и условия](COMPATIBILITY.md) · [Влияние 87U на сборки](BUILD-IMPACT.md).

## Импорт и помощь

Импорт переносит выбранные блоки, списки, blobs и SmartDNS. Встроенные Lua поставляются с пакетом. Адреса своих устройств настройте отдельно.

В **«Поделиться»** можно выбрать даже одну стратегию, один список или один DNS с его сайтами. Остальное не прикладывается автоматически. **«Предпросмотр» → проверка состава → скачать JSON или отправить**, если оператор включил отправку. После правок повторите предпросмотр. Для стратегии, файлов и DNS обязателен оператор.

При сбое сначала сохраните диагностику, затем меняйте настройки или перезагружайте роутер. Отправка добровольная, автоматической отправки нет. [Памятка](USAGE.md) · [Диагностика](DIAGNOSTICS.md) · [DPI Detector](DPI-DETECTOR.md) · [Обновление](PACKAGE-UPDATES.md).
