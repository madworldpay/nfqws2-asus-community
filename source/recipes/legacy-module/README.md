# Backend NFQUEUE для RT-AC87U / Merlin 384.13_10

Этот дополнительный модуль относится только к точному проверенному образу.
Прошивка и ядро не заменяются. Загрузчик проверяет модель, версию, архитектуру,
хэши трёх штатных файлов и самого модуля; штатные проверки vermagic и
MODVERSIONS не отключаются. Несовпадение не разрешает принудительную загрузку.
Модуль не предназначен для HGG, других моделей или других выпусков Merlin.

Источник: [Merlin tag384.13_10](https://github.com/RMerl/asuswrt-merlin.ng/tree/384.13_10),
commit `26e1f3f17a2f29ba7cb9013c67142f8a8c8adfd7`, каталог
`release/src-rt-6.x.4708/linux/linux-2.6.36`.
`nfnetlink_queue.c` скопирован без изменений; лицензия — GPLv2, файл COPYING.
Официальный [toolchain](https://github.com/RMerl/am-toolchains):
`brcm-arm-sdk/hndtools-arm-linux-2.6.36-uclibc-4.5.3`, GCC4.5.3.
Полное дерево исходников и заголовков доступно по закреплённому commit выше.

`kernel.config` восстановлен из config_base.6a и правил RT-AC87U точного
исходника. В Module.symvers — CRC экспортов оригинального ядра, извлечённые
из таблицы __kcrctab, а не вычисленные с произвольной конфигурацией.
Исходный TRX имеет SHA256
`06b7d1d52c81519797cb19d61aa9345a33ce06e5badd4ca5e466cf86eb629cf4`.
Все семь CRC контрольного штатного xt_NFQUEUE совпали; его пересобранный
машинный код совпал побайтно. Для backend проверены 48 требуемых экспортов.

Для воспроизведения используйте отдельное рабочее дерево точного commit:

```sh
python3 build-module.py --source /path/to/asuswrt-merlin.ng \
  --toolchain /path/to/hndtools-arm-linux-2.6.36-uclibc-4.5.3
```

Компилятор требует совместимых 32-битных библиотек хоста. При необходимости
передайте их каталог через `--host-libs`; системные файлы скрипт не меняет.
Скрипт изменяет только указанное рабочее дерево сборки, не роутер.
Внешний каталог сборки задан относительным именем `community-nfqueue`:
личные пути сборочной машины не попадают в строку __FILE__ модуля.
После strip-debug SHA256 поставляемого файла должен быть
`1e5fd88ebf5830d56f6b151de0c791f02b3c3db0a539490fbf32709add0151ab`.

Остановка NFQWS2 убирает собственные правила и процесс. Модуль автоматически
не выгружается: он может использоваться другим обработчиком. Для полного
отката после остановки всех NFQUEUE-процессов можно выполнить
`rmmod nfnetlink_queue`; при занятости ядро откажет. Никаких force-параметров
не требуется. Перезагрузка без запуска пакета возвращает исходный набор ядра.
