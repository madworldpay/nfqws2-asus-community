# Совместимая сборка DPI Detector для старого ARM

Это DPI Detector v5.0.0-alpha.21 из неизменённых исходников
[commit a09d03b58d452c71bd63a9b3d410713dd22049f6](https://github.com/Runnin4ik/dpi-detector/tree/a09d03b58d452c71bd63a9b3d410713dd22049f6).
Алгоритмы и оригинальное меню сохранены. ARMv5TE и C-код для ARM926EJ-S
используют soft-float и не требуют VFP. Официальный ARMv7-файл на испытанном
RT-AC87U завершался с SIGILL.

Файл `dpi-detector-armv5te`: 3778448 байт, SHA256
`c0e0045bab2ae654a9f0fef125602fc042b6f54705afdfa0d6bfc10557e74863`.
Лицензия MIT и авторство оригинала сохранены в `support/dpi-detector-MIT.txt`.
В ARM-IPK файл хранится как данные с режимом0644; исполняемая копия создаётся
только установкой по согласию. Для основного ABI `armv7-2.6` выбирается этот
файл, для `armv7-3.2` и `aarch64-3.10` — официальные скачиваемые файлы.
Уже установленный и проверенный официальный alpha.21 для `armv7-2.6`
сохраняет работоспособность после обновления пакета: прежний SHA256 остаётся
разрешён только для такой установки. Произвольные и изменённые файлы не
принимаются; повторная установка поверх рабочего инструмента не требуется.

## Воспроизведение

Использованы Linux x86_64, Rust1.98.1 с target `armv5te-unknown-linux-musleabi`
и Zig0.13.0. Подготовьте чистый checkout указанного commit, локальные Cargo
dependencies по его Cargo.lock, toolchain Rust с установленным target и Zig.
Скрипт не скачивает зависимости и собирает `--offline --locked`.

```sh
python3 asus/dpi/legacy/build.py \
  --source /path/to/dpi-detector-source \
  --cargo-home /path/to/cargo-cache \
  --rustup-home /path/to/rustup \
  --zig /path/to/zig-0.13.0/zig \
  --target-dir /path/to/dpi-build \
  --output /path/to/dpi-detector-armv5te
```

Пути исходников и инструментов заменяются стабильными префиксами в бинарнике.
При несовпадении закреплённого SHA256 результат не сохраняется. Использованный
при проверке архив исходников имел SHA256
`baeb1f8fe0624224b7079c2fac5da40bf15350447774117720cfaa3a4c4657d4`;
357 файлов сравнены с точным upstream-архивом без различий.

## Границы аппаратной проверки

На RT-AC87U / Merlin384.13_10 проверены версия, справка и короткий прогон всех
семи групп: три штатных домена, два TCP-адреса, три DNS-протокола и профили
Rustls/Chrome146. Число соединений, таймауты и размеры передачи ограничены
входными настройками эксперимента. Все группы завершились, stderr пуст;
оригинальный сохранённый TXT распознан в очищенный JSON без нового запуска.

Это проверка совместимости бинарника и формата отчёта. Она не означает,
что каждый сервис доступен, все встроенные цели проверены или подтверждены
скорость, видео, голос, IPv6 и длительная работа под нагрузкой.
