# Подписанные дополнения импорта

Публичные данные владельца для Build92 и новее. Это резервный источник нового каталога дополнений; основной адрес профилей не меняется. `v1/catalog.json` содержит подписанную оболочку, `v1/files/<sha256>.json` — неизменяемые документы. Закрытый ключ находится вне репозитория. Обновление совместимых перечней доменов не требует пересборки роутерного пакета.

Порядок подготовки и ограничения: [profile-catalog/ADDONS.md](../project/profile-catalog/ADDONS.md). Начальный Riot охватывает только веб-домены: подтверждённая работа матча/голоса и обработка всех портов или AS6507 не заявляются.
