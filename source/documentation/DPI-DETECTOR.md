# DPI Detector

Панель показывает команду для вашей системы: `/opt/bin/nfqws2-dpi` на ASUS/Entware или `/usr/bin/nfqws2-dpi` на OpenWrt. Доступность оригинального DPI зависит от архитектуры.

Необязательная сетевая диагностика с самого роутера. Она не нужна для работы
NFQWS2 и не заменяет проверку с клиентского устройства.

Новый тест запускается по SSH. В окне **«Экспорт / поделиться»** выбирают уже
сохранённый результат. **«Собрать диагностику»** собирает сведения о роутере,
а тесты DPI не запускает.

1. Откройте **«Экспорт / поделиться»** и установите DPI Detector.
2. По SSH на роутере запустите оригинальное меню:

```sh
/opt/bin/nfqws2-dpi
```

3. Выберите нужные проверки. В оригинальном меню нажмите **S** для сохранения TXT.
4. В панели нажмите **«Обновить результаты»**. Результат можно посмотреть,
   скачать или выбрать для отправки через предпросмотр.

Исходный TXT остаётся локальным и может содержать сведения о сети.
Для отправки формируется отдельный очищенный JSON с распознанными показателями;
он может быть частичным. Тесты для этого повторно не запускаются.

На результаты влияют DNS, VPN, NFQWS2 и маршруты. Тест с самого ASUS может идти
другим путём, чем телефон или ПК. Сравнивайте одинаковые цели и условия.

В режиме **«Только указанных устройств»** для проверки собственного исходящего
трафика роутера добавьте его WAN IPv4 в выбор обработки. В режиме **«Всех устройств»**
это обычно уже учтено. Подсказка **«?»** у DPI показывает, как проверить исходный
адрес маршрута. Проверка с телефона или ПК при этом остаётся отдельным измерением.

При чтении отчёта смотрите на протокол: HTTP, TLS и QUIC проверяются отдельно.
`—` у QUIC может означать, что сервер его не поддерживает; `CLOSED` — что сервер
ответил, но закрыл рукопожатие. Работу видео и голоса оценивайте в самом приложении,
а отчёт используйте для поиска причины различий.

Для `armv7-2.6` предусмотрена совместимая сборка тех же исходников:
обычный официальный ARMv7-бинарник не запускался на испытанном 87U.
Это особенность бинарника DPI Detector, а не запрет NFQWS2 или SmartDNS.
