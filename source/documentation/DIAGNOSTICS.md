# Диагностика

**«С чего начать»** показывает чекап и незавершённые этапы.
**«Проверка ARK»** помогает подготовить ASUS, если модуль мешает доставке пакетов.
Неизвестный внутренний флаг сам по себе не доказывает неисправность. Загруженный
ARK показывается отдельно; если подготовка выполнена, следуйте подсказке о ручной
перезагрузке и повторной проверке.

| Что видно | Что проверить |
|---|---|
| Процесса нет | Лог запуска, возможности ядра и выбранный WAN |
| Процесс есть, очередь не растёт | Клиента, путь трафика, новые соединения и ARK |
| Одни сайты работают, другие нет | Стратегию, DNS/CDN, IPv4/IPv6 и протокол |
| Разные результаты на клиенте и роутере | Разные источники трафика и VPN |
| После настройки DNS пропали имена | Статус SmartDNS и возврат прежнего DNS |

Проверка очереди показывает поступление пакетов. Она не подтверждает работу
сайта, видео или голосового соединения. Открывайте сам сервис с выбранного клиента.

## Сохранить сведения

При сбое сначала откройте **«Экспорт / поделиться»**, выберите диагностику
и подготовьте **«Предпросмотр»**. Проверьте состав, скачайте JSON или отправьте
его через публичный канал. Панель поясняет отсутствие канала, поддержки v4 или
HTTPS. Изменённая владельцем конфигурация, в том числе отключение отправки,
сохраняется. Автоматической отправки нет.
Сохраните данные до перезапуска: после него признаки отказа могут исчезнуть.

Для более подробной сетевой проверки есть отдельный [DPI Detector](DPI-DETECTOR.md).
