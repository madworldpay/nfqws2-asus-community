# Профили устройств · бета

Это необязательный режим NFQWS2 для ASUS/Entware и OpenWrt. Он позволяет
назначить отдельную стратегию выбранным устройствам домашней сети.
По умолчанию работает **«Общий»** режим с обычной конфигурацией NFQWS2.
Открытие вкладки **«Устройства · бета»** само по себе ничего не включает.
Профили действуют на трафик, проходящий через этот роутер.

[Реальные снимки общего режима, библиотеки, карточек и предпросмотра](../SCREENSHOTS.md#build99-device-profiles).

## Быстрый запуск

1. Сначала убедитесь, что общая стратегия работает на нужном устройстве.
   Откройте в панели **«Устройства · бета»**.
2. Раскройте **«Библиотека стратегий»**. Можно сохранить текущую стратегию,
   добавить единый JSON-экспорт с нужными файлами или выбрать вариант из каталога.
   Импорт добавляет стратегию в библиотеку; он не включает её для клиентов.
   Доверие к Lua из файла или каталога подтверждается отдельной галочкой:
   включайте её только для знакомого вам источника.
3. Добавьте клиентов из **«Известные роутеру устройства»** или укажите их
   вручную по IPv4/IPv6, MAC либо обоим адресам. Нужен адрес отдельного
   устройства; подсети в этом поле не поддерживаются.
4. Выберите режим **«По устройствам»**, добавьте карточку профиля, выберите
   стратегию и отметьте клиентов. Включённые карточки проверяются сверху вниз.
   Если клиент отмечен в нескольких карточках, действует первая подходящая.
   Порядок можно изменить перетаскиванием за ручку либо кнопками **↑/↓**, в том
   числе на телефоне.
5. Откройте **«Предпросмотр»** и проверьте назначения и предупреждения.
   Нажмите **«Сохранить черновик»**.
6. Нажмите **«Применить сохранённый режим»** — это отдельное подтверждение применения.
   Перед этим проверьте галочку **«Запустить службу после применения»**:
   она определяет, должна ли NFQWS2 работать после завершения операции.
7. Дождитесь итогового статуса в **«Рабочий режим»**. Проверьте нужные сайты,
   видео или приложения с выбранного устройства, создав новые соединения.
   Успешное применение не доказывает, что стратегия подходит вашему провайдеру.

**Сохранить ≠ применить.** Предпросмотр и сохранение черновика не меняют
правила обработки трафика и не перезапускают службу. После правок черновик
нужно сохранить заново и отдельно применить. Изменение библиотеки также
не включает стратегию автоматически.

## Общая стратегия и приоритеты

Устройства без подходящей включённой карточки используют текущую общую
стратегию. Действующие общие исключения сохраняются. Выбор **«Текущая
стратегия»** в карточке обращается к обычной конфигурации NFQWS2; сохранение
её в библиотеку создаёт отдельный вариант для последующего выбора.
У сохранённых вариантов свои ресурсы и `auto.list`.

Чтобы вернуться к обычной работе, выберите **«Общий»**, сохраните черновик
и примените сохранённый режим. Просто переключить переключатель на странице
недостаточно. Список устройств и карточки можно подготовить заранее,
оставив рабочий режим общим.

## Как определяются устройства

Список клиентов строится из локальных DHCP-аренд, таблицы соседей и ARP
на LAN-интерфейсах роутера. Наличие записи означает, что роутер знает клиента;
это не проверка присутствия в сети в данный момент. Если данные недоступны
или неполны, используйте ручное добавление и проверьте предупреждения.

Для записи с MAC применяются IP, найденные для этого MAC при текущей проверке
LAN. Старые IP из сохранённого черновика не используются как запасная замена.
Если MAC не удалось сопоставить с адресом или адрес неоднозначен, проверьте
предпросмотр: такое назначение не следует считать действующим.
После смены IP обновите список, проверьте назначения и снова примените режим.
Для записи только по IP полезно закрепить адрес за устройством в DHCP:
при передаче этого IP другому клиенту правило будет относиться уже к нему.

IPv6 требует включённой обработки IPv6 в общей конфигурации NFQWS2.
Профиль сам по себе её не включает. Проверяйте тот протокол и тот маршрут,
которыми пользуется приложение.

## Лимиты беты

| Что ограничено | Лимит |
| --- | --- |
| Сохранённые стратегии в библиотеке | 8 |
| Карточки приоритетов | 16 |
| Дополнительные процессы NFQWS2 | 4 помимо общего |
| Устройства в черновике | 128 |

Карточка профиля и дополнительный процесс — разные вещи. Несколько карточек
с одной выбранной стратегией используют один её процесс. Разные стратегии
помимо общей требуют дополнительных процессов; 16 карточек не дают
16 независимых движков. Каждый такой процесс расходует дополнительную ОЗУ,
поэтому на роутерах с небольшим объёмом памяти начните с одного профиля
и проверьте стабильность под своей нагрузкой. Фиксированный расход памяти
для всех стратегий не обещается.

DNS остаётся **общим для всех устройств**. Импорт стратегии в библиотеку
не создаёт отдельный SmartDNS для её клиентов. Если результат зависит от DNS,
проверьте действующие общие настройки и работу приложения отдельно.

## Применение, ошибки и обновление пакета

Рабочий режим меняется только после явного применения с подтверждением.
Операция показывает этап и итог; она продолжается и после закрытия вкладки.
При возвращении откройте **«Рабочий режим»** и обновите состояние.
Не считайте закрытие страницы отменой уже начатого применения.

Если применение или запуск завершились ошибкой, механизм восстановления
пытается вернуть прежний режим и прежнее состояние службы.
Проверьте итог операции: панель различает подтверждённое восстановление
и случай, когда его подтвердить не удалось. Кнопка **«Скопировать причину»**
копирует этап, код и результат восстановления для разбора. Если буфер обмена
недоступен, текст можно выделить и скопировать вручную. Не повторяйте
применение вслепую, пока не проверили показанную причину.

**Перед обновлением основного пакета при активных профилях беты сначала
примените «Общий» режим** и дождитесь успешного результата. После обновления
проверьте сохранённые материалы и при необходимости отдельно примените
режим **«По устройствам»**. Автоматический перенос активного режима между
версиями беты не гарантируется.

Одна копия стратегии содержит не более 256 файлов ресурсов суммарным объёмом до 2 MiB, включая создаваемые обучаемые списки. Превышение отклоняется до сохранения копии.
