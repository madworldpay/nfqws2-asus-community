# Как сравнивать стратегии через DPI Detector

[English](DETECTOR-COMPARISON.en.md)

**Detector помогает понять, что изменилось после импорта стратегии, и отделить DNS, соединение и передачу данных. Оценивайте нужный вам сервис, а не только процент OK.**

Ниже — личный пример линии DOM.RU в Тульской области. Это не рекомендация выбирать DOM.RU для другого оператора или региона: правила фильтрации различаются, в том числе у абонентов одного провайдера. Выбирайте профиль под свою сеть и проверяйте результат самостоятельно. Автоматического выбора этого профиля нет.

## Одна завершённая пара измерений

Один ASUS GT-BE19000AI, официальный движок zapret2 1.0.7 с fastpath и DPI Detector v5.0.0-alpha.21. В обоих запусках NFQWS2 на ASUS включён; дополнительный обход не использовался. Тесты **1, 2, 3**, IPv4, параллельность **50**, тайм-аут **8 секунд**.

- **Штатная стратегия из пакета:** 5 ноября 2026, **18:59:54 UTC / 21:59:54 МСК**, конфигурация `f516be08…`.
- **Личная настроенная стратегия:** **19:01:02 UTC / 22:01:02 МСК**, конфигурация `9964bf6a…`.

Это сравнение двух стратегий с работающим NFQWS2. Измерение «без обхода / с обходом» было бы отдельной парой с явно отмеченными состояниями OFF/ON. Исходный вывод этой пары сохранён до разбора чисел; таблица показывает успешные проверки и их полные знаменатели.

| Проверка | Штатная стратегия пакета | Личный пример DOM.RU |
| --- | ---: | ---: |
| TCP / передача данных (TCP16) | 62/110 | 98/110 |
| HTTP | 15/35 | 32/35 |
| TLS 1.2 | 31/35 | 34/35 |
| TLS 1.3 | 29/35 | 33/35 |
| QUIC | 16/21 | 17/21 |
| DNS через HTTPS (DoH) | 33/37 | 33/37 |
| DNS через TLS (DoT) | 31/34 | 31/34 |
| Обычный UDP DNS | 49/49 | 49/49 |

В этой паре личная стратегия улучшила HTTP, TLS и TCP16; DNS-показатели совпали, QUIC изменился на одну проверку. Ошибки остались. Это два последовательных запуска на одной линии: DNS-адреса целей, состояние серверов, нагрузка и фильтрация могут меняться. Для устойчивого вывода повторите сравнение; время выполнения Detector не является измерением скорости Интернета.

**Результат 98/110 относится к личной конфигурации `9964bf6a…`. Кандидат публичного профиля DOM.RU v4 отличается: из него исключены диагностические IP-ветви и отдельный блок сайтов торрент-трекеров. Этой таблицей не подтверждается такой же результат публичного профиля.**

## Что означают проверки

| Слой | На что смотреть |
| --- | --- |
| DNS, DoH, DoT | Проходят ли запросы соответствующим способом. Неожиданный резолвер или изменённый ответ помогает искать причину, но отчёт не доказывает отсутствие всех DNS-утечек. |
| HTTP, TLS 1.2/1.3 | Ответы тестовых сайтов и работа разных вариантов TLS. Успешное рукопожатие само по себе не подтверждает полный ответ, видео или голос. |
| TCP16 / передача данных | Помогает заметить обрыв после установления соединения, в том числе около 16 КиБ. Открытого TCP-порта или успешного TLS недостаточно для вывода о полной доставке. |
| QUIC | Отдельный протокол поверх UDP. Отсутствие его поддержки у цели не равно блокировке; читайте статус, а не только общий процент. |

Один тайм-аут, TLS alert или закрытие соединения не доказывает блокировку IP. Процент OK относится к выбранным тестам и не означает долю работающих сайтов Интернета.

## Как проверить свой импорт

1. Откройте **DPI Detector**, запустите тесты 1–3 и нажмите **S** в меню результатов. Сохраните TXT до изменения стратегии; запишите дату, выбранный профиль и условия.
2. В **«Импорт профиля»** выберите подходящий профиль из подписанного облака, свой JSON или **«Вставить стратегию Keenetic»**. Проверьте блоки, все нужные списки/blobs и недостающие зависимости. Просмотрите «было / станет»; DNS выбирается отдельно. [Подробнее об импорте](../IMPORT.md).
3. Сохраните выбранные изменения, перезапустите NFQWS2 и проверяйте новые соединения. Не меняйте одновременно профиль, DNS, VPN и набор тестов: иначе причина отличий будет непонятна.
4. Повторите те же тесты Detector с теми же параметрами и без второго обхода на пути; снова нажмите **S**. Сравните отдельные строки отчётов. При переменном результате повторите прежний и новый варианты.
5. На выбранном устройстве откройте нужный сервис: проверьте страницу, запуск и перемотку видео, сообщения или голос. Выбирайте по этим задачам. Если стало хуже, используйте отмену последнего импорта или верните сохранённый профиль.

Закрытие окна Detector останавливает его текущие тесты. Сохранённый TXT найдите после обновления списка в **«Экспорт / поделиться»**. Detector не применяет стратегию и не запускает подбор автоматически. [Управление, справка и отчёты](../DPI-DETECTOR.md).
