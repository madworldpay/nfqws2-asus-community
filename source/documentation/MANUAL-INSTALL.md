# Ручная установка IPK

Для готовой Entware. [Установка одной командой](QUICKSTART.md#1-установить).

## 1. Выбрать пакет

В SSH роутера проверьте архитектуру:

```sh
/opt/bin/opkg print-architecture
```

| Архитектура Entware | Пакет |
|---|---|
| `armv7-2.6` / `armv7-3.2` | ARMv7 |
| `aarch64-3.10` | AArch64 |

Скачайте подходящий IPK и `SHA256SUMS` из [актуального выпуска](https://github.com/madworldpay/nfqws2-asus-community/releases/latest).
Проверьте скачанный файл на компьютере: в Windows PowerShell —
`Get-FileHash .\имя-файла.ipk -Algorithm SHA256`, в Linux — `sha256sum имя-файла.ipk`.
Вместо `имя-файла.ipk` укажите название скачанного IPK.
Сравните результат со строкой этого файла в `SHA256SUMS`.

## 2. Передать на роутер

Подготовьте папку на накопителе Entware:

```sh
mkdir -p /opt/tmp
```

В Windows передайте проверенный файл через WinSCP как `/opt/tmp/nfqws2-asus.ipk`.
Для штатного SSH ASUS выберите протокол SCP.

## 3. Установить

В SSH роутера для **первой установки** выполните:

```sh
/opt/bin/opkg update
NFQWS_ASUS_NO_START=1 /opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Обработка останется выключенной до настройки. Эта же команда подходит для
обновления, если службу нужно оставить выключенной.

Для обновления **с запуском NFQWS2 после установки** используйте:

```sh
/opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Обычный `opkg install` пытается запустить службу после установки. Если хотите
автоматически сохранить её прежнее состояние, обновляйтесь через
[панель](PACKAGE-UPDATES.md#через-панель) или [установщик одной командой](QUICKSTART.md#1-установить).
Зависимости загружаются из Entware. При ошибке сохраните вывод установки для диагностики.

## 4. Открыть панель

Откройте `http://IP-роутера:90` и продолжите с [настройки](QUICKSTART.md#2-настроить).
Для удаления и возврата настроек — [отдельная инструкция](INSTALL.md#остановить-или-удалить).
