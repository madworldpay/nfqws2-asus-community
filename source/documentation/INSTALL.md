# Установка и удаление

<a id="asus-entware"></a>

## ASUSWRT-Merlin / Entware

### Перед установкой

Сохраните настройки ASUS.

**Если Entware уже работает в `/opt`, переходите к команде установки.**
На свежей ASUSWRT-Merlin сначала подготовьте Entware:

1. Подключите USB-накопитель с Linux-файловой системой — обычно ext4; ext2/ext3 также подходят. Перед форматированием сохраните нужные файлы с накопителя.
2. Включите SSH для локальной сети в **«Администрирование → Система»** и подключитесь к роутеру с учётной записью администратора ASUS.
3. В SSH выполните `amtm`, выберите `ep` и дождитесь завершения установки Entware.
4. Нажмите `e`, затем Enter, чтобы выйти из меню `amtm` обратно в ту же SSH-консоль. Проверьте Entware командой `/opt/bin/opkg print-architecture`.

| Архитектура Entware | IPK |
|---|---|
| `armv7-2.6` / `armv7-3.2` | ARMv7 |
| `aarch64-3.10` | AArch64 |

[Официальная инструкция Entware](https://github.com/RMerl/asuswrt-merlin.ng/wiki/Entware).

### Установить одной командой

Скопируйте [общую команду установки](QUICKSTART.md#install-command) в SSH-консоль роутера. Установщик выберет пакет для ASUS и проверит его SHA-256. Для установки нужны 128 МБ свободного места в Entware и 32 МБ доступной оперативной памяти.

После настройки запустите NFQWS2 из панели. При обновлении сохраняются настройки и состояние службы. Чтобы выполнить проверку скачанным установщиком, используйте `sh install.sh --check`.

### Установить IPK

Это ручной способ установки. Файл можно передать через WinSCP/SCP
или скопировать на USB по Samba обычным файловым менеджером.
[Перенос через Проводник и сопоставление путей USB](MANUAL-INSTALL.md#2-передать-на-роутер).

Для установки скачанного файла проверьте его SHA256 по `SHA256SUMS` выпуска,
передайте IPK в `/opt/tmp/nfqws2-asus.ipk` и выполните:

```sh
NFQWS_ASUS_NO_START=1 /opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Обработка останется выключенной до настройки. Зависимости устанавливаются из Entware.

### Первый запуск

Откройте `http://IP-роутера:90`.

**Вход в панель ASUS:** используйте логин и пароль администратора роутера.
Если панель не может прочитать системные учётные данные ASUS, автоматически
включается резервный вход: **логин `root`, пароль `asus`**.
Ранее заданный отдельный пароль панели сохраняется при обновлении — используйте его.
Кнопка **«Сменить пароль»** позволяет задать свой пароль панели.

**«Проверка ARK»** предлагает подготовку с резервной копией только когда она нужна.
Перезагрузка для применения выполняется вручную.

Выберите WAN, клиентов и стратегию, сохраните настройки. При необходимости
откройте SmartDNS и пройдите **«Проверить профиль» → «Подключить» → подтверждение**. Затем запустите NFQWS2 и проверьте сервис с клиента.
IPv6-обработка по умолчанию выключена; это не отключает IPv6 прошивки.

### Остановить или удалить

Для временной остановки:

```sh
/opt/etc/init.d/S51nfqws2 stop
```

Перед удалением сохраните профиль. Если подключён SmartDNS, сначала нажмите
**«Вернуть прежний DNS»**. Если нужна исходная конфигурация ARK, восстановите её
из бэкапа до удаления панели. Затем:

```sh
/opt/bin/opkg remove nfqws2-asus
```

Пакет снимает свои правила и службы. Настройки, списки и журналы сохраняются
для повторной установки; Entware и его общие зависимости остаются.
Если обязательный конфиг отсутствует, пакет восстанавливает текущий шаблон и
только нужные ему отсутствующие штатные списки. Существующие файлы сохраняются.
При ошибке остановки сохраните диагностику и разберите причину, не применяйте force.

## Keenetic и Netcraze

Включите компонент OPKG в настройках роутера и выберите накопитель для Entware. Когда Entware установится, войдите в её SSH-консоль как `root`. Для установки вручную узнайте архитектуру командой `opkg print-architecture`. [Быстрый старт](QUICKSTART.md#install-command) · [Пакеты для ручной установки](DOWNLOADS.md#keenetic).

В домашней сети откройте `http://<адрес-роутера>:90/nfqws-community/`. Чтобы удалить панель сообщества, выполните в Entware `opkg remove nfqws2-keenetic-community`. Штатной службой NFQWS2 управляет пакет `nfqws2-keenetic`.

## OpenWrt

Подключитесь к роутеру по SSH как `root` и выполните [общую команду установки](QUICKSTART.md#install-command). Установщик подберёт нативный пакет OpenWrt.

После установки откройте адрес панели, выберите устройства и стратегию, сохраните
настройки и запустите NFQWS2. Для остановки: `/etc/init.d/nfqws2-native stop`.
Перед удалением сохраните профиль и верните прежний DNS через SmartDNS. Удаление:
`opkg remove nfqws2-native` для 24.10 или `apk del nfqws2-native` для 25.12.
