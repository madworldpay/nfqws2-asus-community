# Установка и удаление

## ASUSWRT-Merlin / Entware

### Перед установкой

Сохраните настройки ASUS. Нужны SSH и работающий Entware в `/opt`.
Архитектуру пакетов Entware можно узнать командой:

```sh
/opt/bin/opkg print-architecture
```

| Архитектура Entware | IPK |
|---|---|
| `armv7-2.6` / `armv7-3.2` | ARMv7 |
| `aarch64-3.10` | AArch64 |

Для RT-AC87U используйте исправный USB-накопитель с рабочим автозапуском Entware.

### Установить одной командой

В SSH роутера с готовой Entware выполните:

```sh
( nfqws_url=https://raw.githubusercontent.com/madworldpay/nfqws2-asus-community/main/install.sh; nfqws_file=$(mktemp) && trap 'rm -f "$nfqws_file"' 0 && { curl -fL --connect-timeout 10 --max-time 60 "$nfqws_url" -o "$nfqws_file" || wget --https-only -T 20 -t 2 -O "$nfqws_file" "$nfqws_url"; } && sh "$nfqws_file" )
```

Команда одинаковая для поддерживаемых ARMv7 и AArch64.

Установщик скачивает актуальный IPK по HTTPS и сверяет SHA256. Для установки нужны
`curl` или GNU `wget`, не менее 128 МБ свободного места в Entware и 32 МБ доступной
оперативной памяти. Временные файлы размещаются в `/opt/tmp` и удаляются после
завершения. Чужие файлы установщик не удаляет.

Первый запуск обработки выполняется в панели после настройки. При обновлении
сохраняются настройки и выбранное состояние службы «включено / выключено». Если актуальная версия
уже установлена, повторная команда только покажет ссылку на панель.

### Установить IPK

Это ручной способ установки. Файл можно передать через WinSCP/SCP
или скопировать на USB по Samba обычным файловым менеджером.
[Перенос через Проводник и сопоставление путей USB](MANUAL-INSTALL.md#2-передать-на-роутер).

Для установки скачанного файла проверьте его SHA256 по `SHA256SUMS` выпуска,
передайте IPK в `/opt/tmp/nfqws2-asus.ipk` и выполните:

```sh
NFQWS_ASUS_NO_START=1 /opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Обработка останется выключенной до настройки. Зависимости устанавливаются из Entware.

### Первый запуск

Откройте `http://IP-роутера:90`. По умолчанию используются данные администратора ASUS.
**«Проверка ARK»** предлагает подготовку с резервной копией только когда она нужна.
Перезагрузка для применения выполняется вручную.

Выберите WAN, клиентов и стратегию, сохраните настройки. При необходимости
откройте SmartDNS и пройдите **«Проверить профиль» → «Подключить» → подтверждение**. Затем запустите NFQWS2 и проверьте сервис с клиента.
IPv6-обработка по умолчанию выключена; это не отключает IPv6 прошивки.

### Остановить или удалить

Для временной остановки:

```sh
/opt/etc/init.d/S51nfqws2 stop
```

Перед удалением сохраните профиль. Если подключён SmartDNS, сначала нажмите
**«Вернуть прежний DNS»**. Если нужна исходная конфигурация ARK, восстановите её
из бэкапа до удаления панели. Затем:

```sh
/opt/bin/opkg remove nfqws2-asus
```

Пакет снимает свои правила и службы. Настройки, списки и журналы сохраняются
для повторной установки; Entware и его общие зависимости остаются.
Если обязательный конфиг отсутствует, пакет восстанавливает текущий шаблон и
только нужные ему отсутствующие штатные списки. Существующие файлы сохраняются.
При ошибке остановки сохраните диагностику и разберите причину, не применяйте force.

Если данные входа ASUS недоступны панели, резервный вход — `root` / `asus`.
Кнопка **«Сменить пароль»** задаёт отдельный пароль панели.

## OpenWrt

Нативный пакет устанавливается без Entware. В SSH роутера от `root` выполните:

```sh
( nfqws_url=https://raw.githubusercontent.com/madworldpay/nfqws2-asus-community/main/install.sh; nfqws_file=$(mktemp) && trap 'rm -f "$nfqws_file"' 0 && { curl -fL --connect-timeout 10 --max-time 60 "$nfqws_url" -o "$nfqws_file" || uclient-fetch -T 20 -O "$nfqws_file" "$nfqws_url"; } && sh "$nfqws_file" )
```

После установки откройте адрес панели, выберите устройства и стратегию, сохраните
настройки и запустите NFQWS2. Для остановки: `/etc/init.d/nfqws2-native stop`.
Перед удалением сохраните профиль и верните прежний DNS через SmartDNS. Удаление:
`opkg remove nfqws2-native` для 24.10 или `apk del nfqws2-native` для 25.12.
