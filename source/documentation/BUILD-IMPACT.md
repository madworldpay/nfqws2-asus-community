# Что дал тест RT-AC87U

RT-AC87U показал возможность адаптации NFQWS2 к старому ASUS:
для Merlin **384.13_10** понадобились совместимый userspace и точный модуль NFQUEUE.
Эти доработки входят в ARMv7-пакет. Перепрошивка для их применения не требуется.

| Компонент | Для чего |
|---|---|
| ARMv7 runtime | Запуск на Entware `armv7-2.6` и `armv7-3.2` |
| Дополнительный модуль 87U | Только точная проверенная модель/прошивка; не загружается на похожие устройства автоматически |
| Проверка ARK | Отдельная задача NFQUEUE на устройствах с этим модулем |
| SmartDNS hook Merlin | Сохранение пути dnsmasq → SmartDNS после перезапуска DNS |

AArch64-пакету модуль 87U не нужен. SmartDNS не зависит от этого модуля.
Служебные Lua поставляются с пакетом; пользователю не нужно переносить их вручную.

На 87U испытаны 256 МиБ ОЗУ и Entware на USB. Большие списки, blobs, DNS-кэш
и другие службы увеличивают расход памяти и места. Единого минимума для всех
стратегий пока нет; чекап проверяет текущие ресурсы. USB не добавляет ОЗУ.
Если пропадает `/opt`, проверьте USB-накопитель, питание и автозапуск Entware:
от них зависит доступность установленного пакета.

Обновление и восстановление подтверждённого SmartDNS проверены на обоих ASUS.

прошивкой и условиями теста помогают расширять этот список.
