# Обновление

## Разовый переход на новый ключ подписи

Для перехода с прежних сборок на Build 74 или новее один раз нужен установщик.
Прежний закрытый ключ подписи утрачен при удалении сервера без резервной копии.
Старая панель доверяет этому ключу и не может проверить новые выпуски.
Повторите команду своей платформы из раздела «Быстрый старт» главной страницы
проекта. Настройки, списки, данные входа и выбранное состояние службы сохраняются;
следующие обновления снова устанавливаются через панель с GitHub.

Это возвращает возможность получать дальнейшие исправления через панель.
В актуальном выпуске также есть даты стратегий, временный технический канал
по договоренности с Администратором и исправления остановки службы и сообщений
SmartDNS на OpenWrt. Каталог стратегий и приём материалов находятся на ASUS,
отправления доставляются в Gmail; для них и обновлений VPS не требуется.

## Через панель

Панель автоматически проверяет актуальные публичные выпуски GitHub.
Нажмите **«Проверить обновления»**, чтобы узнать, есть ли подходящий выпуск.

В разделе **«Изменения с вашей версии»** показаны описания всех опубликованных
промежуточных билдов, включая целевой, от старых к новым. Описания автоматически
загружаются из публичных выпусков GitHub при открытии окна, без входа в GitHub.
Текст выпусков показан на языке оригинала. Если историю не удалось загрузить
полностью, панель сообщает об этом и оставляет доступным описание целевого
выпуска. Это не мешает подготовке и установке; проверки самого пакета сохраняются.

Эта возможность действует в панели, которая её поддерживает: ранее выпущенные
старые панели не получают новый интерфейс до собственного обновления.

После просмотра изменений:

1. **«Подготовить пакет»** — скачать, проверить подпись, совместимость и место,
   сохранить снимок настроек.
2. **«Установить обновление»** — заменить пакет и дождаться результата.

Панель может временно отключиться. Закрытие вкладки не отменяет установку.
Обновлятор сохраняет настройки, списки, данные входа и прежнее намерение запуска службы.
Прошивка, ARK и маршруты этим действием не настраиваются; перезагрузка не требуется.

Ранее подтверждённый SmartDNS восстанавливается с сохранённым профилем.
Проверьте статус после обновления. Если восстановление не завершено, остаётся
штатный DNS; не считайте это успешным подключением SmartDNS.

## Вручную

Скачайте IPK своей архитектуры из [последнего выпуска](https://github.com/madworldpay/nfqws2-asus-community/releases/latest),
проверьте SHA256 и передайте его на роутер по [инструкции](MANUAL-INSTALL.md). Затем выполните:

```sh
/opt/bin/opkg install /opt/tmp/nfqws2-asus.ipk
```

Повторная установка сохраняет оставленные настройки. Пакет также восстанавливает
отсутствующий обязательный конфиг из текущего шаблона пакета. При существующем
конфиге намеренно удалённые списки не возвращаются.
Не используйте force и не устанавливайте старый пакет поверх нового без разбора причины.
После установки проверьте версию, состояние службы и SmartDNS.

## Если старая панель не находит обновление

Используйте [установщик одной командой](QUICKSTART.md#1-установить) или
[ручную установку актуального IPK](MANUAL-INSTALL.md). Старые панели могли
использовать только частный канал. После обновления доступна установка
через панель без токена и учётной записи GitHub.

Панель проверяет подпись выпуска закреплённым ключом, затем размер и SHA256 пакета.
При ошибке проверки установка не начинается. Существующий частный канал, если
он задан оператором, продолжает использоваться.

Опубликованный номер Build не переиспользуется для другого содержимого.
Автоматического отката версии пакета нет. [Загрузки](DOWNLOADS.md) · [Удаление](INSTALL.md).

После обрыва подготовки можно повторить установку. Собственные настройки канала отправки сохраняются.
