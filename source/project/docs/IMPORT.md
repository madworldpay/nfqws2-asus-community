# Импорт из JSON

JSON — файл с профилем, сохранённый в нашей панели через **«Поделиться» →
«Скачать JSON»**. Его создаёт владелец роутера для переноса настроек или
обмена с другим пользователем. Это может быть ваш файл или полученный от
другого человека; содержание видно до сохранения на роутере.

В полях стратегии показаны реальные пути к приложенным файлам — как в обычном редакторе. Внутренние ссылки JSON преобразуются автоматически; если файла нет или имена конфликтуют, панель отмечает проблему.

Кнопка импорта рядом с «Поделиться» переносит выбранные данные из сохранённого
экспорта панели или одобренного пресета из нашего облака.

1. Сохраните или отмените незавершённые правки в редакторе.
2. Нажмите импорт: **«Из облака»** открывает каталог профилей провайдеров и глобальных стратегий. **«С компьютера (JSON)»** открывает один JSON экспорта либо до пяти JSON-вложений
   из письма: стратегии, ресурсы, DNS. Общий размер — до 4 МиБ.
3. Отметьте нужные блоки, общие параметры, порты, списки, blobs или
   карточки SmartDNS с сайтами. Изначально ничего не выбрано. Текст выбранных
   копий и поля DNS можно поправить; оригинальный JSON не меняется.
   По умолчанию видны назначение, оператор и переданный регион. Текст открывается
   кнопкой «Раскрыть стратегии»; содержимое файлов — отдельной кнопкой.
4. Откройте **«Предпросмотр»**. Если нужны общие определения или файлы,
   **«Выбрать доступные зависимости»** отметит приложенные данные. При отсутствии
   нужного файла добавьте его JSON ресурсов. Скрытые при экспорте адреса и
   неизвестные переменные нужно восстановить в копии самостоятельно.
5. Проверьте «было / станет», новые файлы и другие затронутые блоки.
   «Выбрать всё» отмечает весь доступный состав; для blobs есть отдельная
   общая кнопка. Уже отредактированные копии сохраняются.
   Служебные Lua-файлы входят в пакет и не требуют выбора. Для файла из другой
   сборки нужен совместимый пакет: произвольный Lua автоматически не запускается.
6. Нажмите **«Сохранить выбранное»**. Стратегия сохраняется без перезапуска
   NFQWS2. Когда будете готовы, используйте обычный перезапуск службы.

DNS импортируется **только в черновик** мастера SmartDNS
(вкладка **SmartDNS** в панели).
Выбранные серверы заменяют набор в черновике; записи без серверов могут дополнить
уже имеющийся черновик. Требуются настоящий основной сервер и, при необходимости,
bootstrap; выдуманные значения не подставляются. Работающий DNS не переключается.

Локальные WAN, адреса клиентов, очередь, пользователь процесса и прочие параметры
этого роутера не заменяются настройками из экспорта. Report и DPI служат только
справкой. Имена файлов сохраняются одинаковыми в списках, стратегии и экспорте.
При совпадении имени и SHA256 используется существующий файл. Если содержимое
отличается, предпросмотр показывает замену; прежние байты и права сохраняются
для отмены импорта. Два разных выбранных файла с одним именем требуют выбора
одного из них. Новые списки доступны для записи службе NFQWS2,
включая пополнение auto-hostlist; Lua и blobs сохраняются без права исполнения.
Права уже существующих файлов не меняются. При чтении,
предпросмотре и сохранении Lua не исполняются. Совпадение модели или корректный
синтаксис сами по себе не подтверждают работу стратегии в вашей сети.

**«Отменить последний импорт»** возвращает прежние конфиг и DNS-черновик и файлы:
возвращает заменённые копии и удаляет созданные импортом неизменённые файлы. Если вы уже исправили эти данные, отмена
откажется их перезаписывать. На роутере сохраняется закрытый журнал: текущая
операция и до трёх прошлых резервных копий, суммарно до 8 МиБ. Исходные загруженные
JSON в нём не сохраняются. Ограничения ресурсов: до 128 файлов, 256 КиБ каждый,
512 КиБ содержимого выбранных копий суммарно и до 512 КиБ прежних файлов
для отмены одной операции.

Если ответ на запись не пришёл, нажмите **«Проверить результат»** или повторите
ту же запись. Повторный запрос не создаёт второй импорт. Предпросмотр действует
10 минут; после правок или изменения данных роутера подготовьте его заново.
При прерывании следующая запись проверяет журнал и завершает собственную
операцию либо восстанавливает прежние данные. Чужие изменения сохраняются для
разбора, вместо их автоматической перезаписи.
