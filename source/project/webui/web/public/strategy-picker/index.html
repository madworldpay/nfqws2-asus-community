Настройки подбора

Во время проверки интернет может ненадолго прерваться. Если закрыть вкладку или уйти со страницы, роутер остановит подбор и начнёт возвращать исходные настройки. При потере связи это может занять несколько минут. Чтобы проверить результат, снова откройте подбор.

Создание новой стратегии пока в бета-версии. Роутер пробует разные настройки и повторно проверяет лучшие варианты. Улучшение не гарантируется. Проверки идут по IPv4.

Каждый прогон использует результаты предыдущего. Лучший вариант можно применить после завершения подбора.

Количество прогонов

Следующий прогон начнётся после восстановления настроек и проверки соединения. При остановке или ошибке вся серия завершается.

Одновременные проверки

Обычно достаточно 10–100. Большие значения не гарантируют ускорения подбора.

Какие сервисы важны

Торрент-трекеры в проверке — NNMClub, RuTracker, Rutor и tapochek.net.

Выбранные сервисы влияют на итог. Роутер проверит и другие сайты, чтобы заметить ухудшения.

Свои сайты

Один адрес на строку. Подойдут example.com, https://example.org и 8.8.8.8.

Роутер проверит главную страницу каждого сайта по HTTPS (TLS 1.2 и 1.3). Для IP-адреса нужен сертификат, выданный на этот адрес. Правило для IP может затронуть другие сайты на нём. Сбой защищённого соединения (TLS) может иметь разные причины. Telegram исключён.

Роутер попробует дополнительные настройки соединения. Правила для отдельных сервисов и игр сохранятся.

Сравнение

Роутер сравнил варианты с вашей исходной стратегией и соединением без обхода.

Добавляет HTTPS-правила для NNMClub, RuTracker, Rutor и tapochek.net. Если включите их, проверьте стратегию ещё раз.
