Локальный подбор

Во время смены профилей соединения могут кратковременно прерываться. DNS и сетевые настройки сохраняются. Закрытие страницы не останавливает работу; для отмены нажмите «Остановить и восстановить». Проверки в этой версии выполняются по IPv4.

Генератор стратегий проходит бета-тестирование. Он проверяет методы для HTTP, TLS и QUIC и уточняет поиск по результатам. Полезные приёмы прошлых запусков проверяются заново. Лучшие варианты проходят повторные замеры; улучшение не гарантируется. Каталог готовых стратегий не требуется. Проверки выполняются по IPv4.

Выберите число прогонов заранее — серия выполнится автоматически. Новый прогон учитывает предыдущие проверки. При остановке или ошибке серия прекращается. Стратегия сама не применяется.

Количество прогонов

Укажите число заранее: следующий прогон начнётся автоматически после восстановления настроек и новой проверки условий. При ошибке или остановке серия прекращается. Стратегия сама не применяется.

Цель подбора

Цель «Торрент-трекеры» проверяет сайты NNMClub (nnmclub.to), RuTracker (rutracker.org), Rutor (rutor.info) и tapochek.net.

В режиме «Все сервисы» в первую очередь проверяются YouTube, Instagram, Discord и торрент-трекеры. Остальные сайты остаются дополнительным контролем. Для выбранных сервисов поиск и оценка сосредоточены на их доменах; общие проверки сохраняются для контроля ухудшений.

Свои сайты

Например: example.com, https://example.org или 8.8.8.8. Каждый адрес — с новой строки.

Проверяются корневые HTTPS-страницы по IPv4 с TLS 1.2 и 1.3. Для IP нужен сертификат, действительный для этого IP; домен не подставляется. Ошибка TLS сама по себе не доказывает блокировку. Правило IP может затрагивать другие HTTPS-сайты на том же адресе. Ответ сервера, включая 403, не означает доступность сайта. Telegram не участвует.

Проверяются раздельные и совместные варианты числа повторов TCP/QUIC. Правила отдельных сервисов и игр сохраняются; число попыток ограничено.

Сравнение

Сначала проверяются разные способы обхода, затем лучшие варианты проходят повторные замеры. Итоговая стратегия сравнивается с вашей исходной стратегией и вариантом без обхода.

Четыре сайта добавятся к области HTTPS собранного метода: nnmclub.to, rutracker.org, rutor.info, tapochek.net. Дополнение необязательно и выключено по умолчанию. Показатели выше получены для исходного комплекта до добавления дополнения; после добавления повторите проверку.
