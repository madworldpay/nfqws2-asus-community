# Работа с панелью

Действия в панели общие для ASUS/Entware и OpenWrt.

Вход: `http://IP-роутера:90`. **«С чего начать»** показывает порядок настройки
и состояние этапов. **«?»** даёт пояснение к полю или действию.

## Разделы и применение настроек

- **Настройки** — WAN, устройства, стратегия и параметры обработки.
- **Списки** — файлы, используемые стратегиями.
- **SmartDNS** — DNS для всех сайтов и отдельных доменов.
- **Логи** — сообщения службы.

Сохраняйте изменения и перезапускайте NFQWS2 для применения стратегии.
Сохранённый конфиг и уже запущенный процесс — разные состояния: после правки
стратегии используйте **«Перезапуск»**. Для SmartDNS действует отдельный мастер подключения.

## Редактор и штатные стратегии

В редакторе можно включить визуальный перенос строк: он не меняет текст;
настоящий перевод строки показан отдельно. Предупреждение о кавычках указывает
место возможной ошибки, но не проверяет работоспособность стратегии.

Во вкладке **nfqws2.conf** основные блоки визуально разделены, при этом весь
конфиг можно выделить и скопировать целиком.

Кнопка **«По умолчанию»** возвращает штатные TCP, QUIC и UDP, очищает пользовательский
блок. WAN и выбор устройств сохраняются. Просмотрите результат, нажмите
**«Сохранить»**, затем **«Перезапуск»**. Это возврат стратегий, а не сброс всех настроек роутера.

## Режим работы: Auto, List и All

Поле **«Режим работы»** определяет выбор доменов для обработки.
Оно независимо от поля **«Обрабатывать трафик»**, которое выбирает устройства.

| Режим | Что обрабатывается | Пример применения |
| --- | --- | --- |
| **List** | Домены из пользовательского списка `user.list` | Вы добавили нужные домены и хотите обрабатывать только их |
| **Auto** | Пользовательский список и домены, автоматически добавляемые в `auto.list` при обнаружении проблем; домены из `exclude.list` исключаются | Хотите дополнительно пополнять список по результатам соединений |
| **All** | Весь подходящий под настройки трафик, кроме доменов из `exclude.list` | Хотите обработку без ограничения пользовательским списком доменов |

**Auto не подбирает стратегию обхода автоматически.** Он ведёт автоматический список;
сама стратегия должна подходить вашему подключению. Автоматическое обнаружение
не гарантирует распознавание любой блокировки.

Выбранный режим не отменяет настройки TCP/UDP-портов, протоколов и фильтры стратегии.
Отдельные блоки импортированного профиля также могут содержать собственные фильтры.
**All не означает все устройства:** при выборе только телевизора этот режим
применяется к подходящему трафику телевизора.

## Устройства и трафик самого роутера

В поле **«Обрабатывать трафик»** выберите, для кого работает NFQWS2:

| Выбор в панели | Результат |
| --- | --- |
| **Всех устройств** | Обработка всех клиентов, чей трафик проходит через настроенный роутер |
| **Только указанных устройств** | Обработка только добавленных IP или подсетей; остальные проходят без обработки NFQWS2 |
| **Всех, кроме указанных устройств** | Добавленные IP или подсети исключаются; остальные обрабатываются |

Можно добавить телефон, телевизор, ПК, приставку или другое устройство по его
локальному IP. Например, режим **«Только указанных устройств»** и два адреса
включат обработку только для этих двух устройств. В режиме исключений те же
адреса, наоборот, останутся без обработки NFQWS2. Доступ в интернет этим не отключается.

IPv4 и IPv6 выбираются отдельно; IPv6-обработка пакета включается
своей галочкой и не отключает IPv6 прошивки. Выбор клиентов NFQWS2 не задаёт
область работы SmartDNS: его профиль подключается отдельно.

В режиме **«Только указанных устройств»** в поле IPv4 введите, например:

- `192.168.1.100` — одно устройство.
- `192.168.1.100 192.168.1.120` — два устройства, адреса через пробел.
- `192.168.1.0/24` — вся указанная подсеть, если именно её нужно выбрать целиком.

Подставьте локальные IPv4 нужных устройств из списка клиентов своего роутера;
кавычки и запятые не нужны. В настройках DHCP-сервера закрепите каждый IPv4
за MAC-адресом соответствующего устройства, чтобы адреса сохранялись после
переподключения. Примеры в подсказке сами поле не заполняют.

Под IPv4-клиентами показаны WAN-адреса самого роутера. Это адреса его интерфейсов,
а не обязательно публичный IP. В режиме выбранных клиентов можно добавить WAN-адрес,
если нужна обработка трафика самого ASUS. VPN и гостевые сети проверяйте отдельно.

EN / RU меняет язык. Тема выбирается в верхнем меню. Смена пароля относится
к отдельной учётной записи WebUI и не меняет пароль ASUS.

Проект бесплатный, отчёты добровольные. Сохраняйте рабочие профили через
**«Экспорт / поделиться»** — для своего возврата или обмена.

## Шаблоны пакетов (blobs)

Блоб — готовый шаблон данных, который стратегия использует для обхода блокировки.
Если сайт, видео или звонок не работают, можно попробовать другой шаблон, не меняя
всю стратегию. Результат зависит от провайдера.

В разделе «Шаблоны пакетов» видны текущий файл и доступные варианты. Выберите
другой файл и сохраните настройки обычной кнопкой. «Загрузить с устройства»
добавляет свой файл `.bin` (до 256 КиБ); сам по себе он не меняет стратегию.
В комплекте 12 шаблонов из официального zapret2: 6 TLS, 5 QUIC и 1 STUN.
Их названия указывают содержимое шаблона, а не список сайтов для обхода.
