# Памятка

Порядок ниже относится к сборке, которая готовится к релизу. [Начало установки](README.md#с-чего-начать) · [Совместимость](COMPATIBILITY.md).

## SmartDNS

Выберите DNS, назначьте ему сайты и нажмите **«Проверить профиль» → «Подключить»**. Проверка сама не меняет DNS роутера. После подключения проверьте связь и подтвердите результат в панели.

**«По умолчанию»** — DNS для сайтов без отдельного назначения. Нужен хотя бы один такой сервер. Без этой галочки сервер обслуживает только назначенные ему сайты.

Фиксированный ответ закрепляет IP сайта. Адрес CDN со временем может измениться. Для отката используйте **«Вернуть прежний DNS»** до удаления пакета. [Подробная настройка и ограничения](SMARTDNS.md).

## Импорт

JSON — файл с профилем, который владелец роутера сохраняет через «Поделиться» → «Скачать JSON». Он нужен для переноса настроек или обмена с другим пользователем. Это может быть ваш файл или полученный от другого человека; содержание видно до сохранения на роутере. Общая база стратегий пока не подключена.

1. Откройте импорт и выберите JSON.
2. Отметьте нужные блоки стратегии, файлы и DNS. Подробности можно раскрыть.
3. Откройте предпросмотр, проверьте замены и сохраните выбранное.
4. Настройте свои устройства. После изменения стратегии перезапустите NFQWS2; DNS подключается отдельно.

Встроенные Lua уже входят в пакет. Для пользовательских списков и blobs нужны соответствующие файлы.

## Поделиться

Можно выбрать один материал: диагностику, сохранённый DPI, стратегию, список, blob или DNS с его сайтами. Невыбранные файлы автоматически не прикладываются. Дополнительные файлы не обязательны для отправки стратегии.

Укажите назначение и интернет-провайдера / оператора для стратегии, файлов или DNS. Нажмите **«Предпросмотр»**. Затем доступны JSON для скачивания и отправка, если оператор проекта включил канал. После изменения выбора или текста повторите предпросмотр. Местоположение и связывание отправок выбираются отдельно.

Пределы вложений: 128 файлов, до 256 КиБ каждый, до 512 КиБ исходных байтов суммарно. Сервер также ограничивает частоту отправок. Письмо автоматически не отправляется.

## Если что-то не работает

Сначала сохраните диагностику и симптомы, затем меняйте настройки или перезагружайте роутер. Процесс, привязка очереди, рост счётчика и работа сервиса — разные проверки. Для сравнения учитывайте DNS и другие средства обработки на пути клиента.

## Перед установкой

Сохраните настройки и используйте оборудование, которым вправе управлять. ПО предоставляется **«как есть»**, без гарантий пригодности для конкретной задачи. Проект бесплатный; отчёты и поддержка разработки добровольные. Сохраняются [авторство и лицензии компонентов](UPSTREAM.md). Это самостоятельный порт, без официальной связи с ASUS, Entware и авторами upstream.
