# Диагностика

Проверяйте трафик с выбранного устройства и состояние службы в панели.
Для проверки через SSH используйте команду своей платформы:

```sh
# ASUS / Entware
/opt/etc/init.d/S51nfqws2 status

# OpenWrt
/etc/init.d/nfqws2-native status
```

**«С чего начать»** показывает чекап и незавершённые этапы.
**«Проверка ARK»** помогает подготовить ASUS, если модуль мешает доставке пакетов.

ARK — модуль обработки трафика в некоторых прошивках ASUS. С ним связаны отдельные
функции QoE, фильтрации и блокировки. Загруженный ARK может мешать передаче пакетов
в NFQUEUE — механизм, через который NFQWS2 получает трафик. Тогда процесс NFQWS2
запущен, но пакеты для обработки не поступают и обход не работает.
Подготовка сохраняет бэкап и выключает связанные функции; затем нужна ручная
перезагрузка через панель ASUS, чтобы проверить работу без загруженного модуля.

**«ARK отсутствует — подготовка не требуется»** — нормальный результат для прошивки без ARK. Переходите к настройке стратегии; отключать несуществующие функции не нужно.
Неизвестный внутренний флаг сам по себе не доказывает неисправность. Загруженный
ARK показывается отдельно; если подготовка выполнена, следуйте подсказке о ручной
перезагрузке и повторной проверке.

| Что видно | Что проверить |
|---|---|
| Процесса нет | Лог запуска, возможности ядра и выбранный WAN |
| Процесс есть, очередь не растёт | Клиента, путь трафика, новые соединения и ARK |
| Одни сайты работают, другие нет | Стратегию, DNS/CDN, IPv4/IPv6 и протокол |
| Разные результаты на клиенте и роутере | Разные источники трафика и VPN |
| После настройки DNS пропали имена | Статус SmartDNS и возврат прежнего DNS |
| Панель показывает обычный DNS вместо SmartDNS | Подключён ли профиль и сохранилось ли перенаправление после запуска VPN или другой службы |
| Обновление не завершилось | Текст ошибки и `opkg status nfqws2-asus`; затем подсказку о восстановлении DNS |
| После импорта результат не изменился | Сохранён ли выбранный состав и выполнен ли перезапуск NFQWS2; DNS подключается отдельно |

Проверка очереди подтверждает поступление только при росте счётчика одной и той же
очереди. После перезапуска службы или при недостаточных данных повторите проверку.
Это не подтверждение работы сайта, видео или голоса — откройте сам сервис с выбранного клиента.

## Технический канал

После договорённости с Администратором откройте **«Технический канал»** внизу панели,
вставьте выданную ссылку целиком и нажмите **«Подключить»**. Дождитесь состояния
**«Ожидает подключения Администратора»**. Отдельные команды PowerShell или PuTTY не нужны.
Для канала нужен вход с заданным паролем панели. Кнопка **«Отключить канал»** закрывает
доступ; по истечении срока и после перезагрузки он также прекращается.

При ошибке сохраните её текст до повторной попытки. Скажите Администратору, включён
ли VPN на компьютере или роутере; переключение VPN во время сеанса может оборвать связь.

## Сохранить сведения

1. Откройте **«Экспорт / поделиться»** и отметьте **«Диагностика роутера»**.
2. Нажмите **«Собрать диагностику»** и дождитесь имени JSON-файла.
3. Откройте **«Предпросмотр»**, проверьте состав, затем выберите **«Скачать JSON»**
   или **«Отправить»**. Для одной диагностики поля сервиса и провайдера не нужны.

Галочка сама по себе диагностику не собирает. Это сведения о состоянии роутера;
тесты DPI запускаются отдельно. Автоматической отправки нет.
Сохраните данные до перезапуска: после него признаки отказа могут исчезнуть.

Чтобы проверить поступление пакетов, в чекапе запустите **«Проверить поступление
в NFQUEUE (10 с)»** и в это время откройте сервис с выбранного клиента. Если
проверяете с самого роутера, учитывайте его WAN-адрес и режим выбора устройств.

Если скорость мала, в комментарии укажите сервис, качество видео и поведение
буфера/перемотки. Отметьте, включён ли VPN и на каком устройстве он работает.
Для сравнения после изменения стратегии заново откройте приложение или браузер,
чтобы появились новые соединения.

Для более подробной проверки откройте **DPI Detector**, установите утилиту
и выполните показанную панелью команду. Сохраните результат клавишей **S**,
затем нажмите **«Обновить результаты»** в панели.

Если канал ещё не настроен, нажмите **«Подключить отправку»**. Затем подготовьте предпросмотр и нажмите **«Отправить»**. Подключение канала само по себе ничего не отправляет; сохранение JSON доступно отдельно.
