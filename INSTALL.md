# Установка

Сначала сохраните настройки ASUS и проверьте [совместимость](COMPATIBILITY.md). Устанавливайте пакет на оборудование, которым вправе управлять; короткая [памятка](USAGE.md) объясняет условия использования. Entware должен быть установлен в `/opt`, работать после загрузки роутера и иметь доступ к своему репозиторию.

## Выбор пакета

```sh
/opt/bin/opkg print-architecture
```

| Основной ABI Entware | Пакет |
| --- | --- |
| `aarch64-3.10` | AArch64 |
| `armv7-2.6` или `armv7-3.2` | ARMv7 |

Наличие дополнительной архитектуры в списке не делает её основной. Установщик проверяет CPU и основной ABI; поддержка NFQUEUE конкретным ядром проверяется отдельно.

Откройте [Пакеты](DOWNLOADS.md), затем нужный файл IPK и нажмите **Download raw file** (значок загрузки). Так же скачайте `SHA256SUMS`. Пока репозиторий приватный, нужен вход в GitHub с доступом к нему; анонимная команда `wget` не скачает приватный пакет.

Скопируйте оба скачанных файла на ASUS, например в `/tmp`, через WinSCP или SCP. В OpenSSH может понадобиться `scp -O`, если штатный SSH ASUS не предоставляет SFTP. Дальнейшие команды выполняются **по SSH на самом ASUS**, в каталоге со скачанным пакетом: Сверьте контрольную сумму файла:

```sh
sha256sum ИМЯ_СКАЧАННОГО_ПАКЕТА.ipk
```

Для AArch64 текущий файл называется `nfqws2-asus_1.3.1-asus6+b16_aarch64-3.10.ipk`, для ARMv7 — `nfqws2-asus_1.3.1-asus6+b16_armv7.ipk`. Сравните результат `sha256sum` со строкой этого файла в `SHA256SUMS`.

Обновите индекс Entware и установите **конкретный скачанный файл**:

```sh
/opt/bin/opkg update
/opt/bin/opkg install ./ИМЯ_СКАЧАННОГО_ПАКЕТА.ipk
```

Это не полностью офлайн-комплект: зависимости PHP и библиотек берутся из Entware. Автозапуск Entware должен быть настроен самим владельцем роутера. Пакет устанавливает собственные init-службы и запускает их после обычной установки.

Для первой установки индекс Entware должен полностью загрузиться: он нужен для поиска зависимостей. Если загрузка индекса зависает или обрывается, сначала проверьте доступ к репозиторию Entware. При обновлении уже работающего пакета, когда зависимости установлены, можно установить скачанный IPK без повторной загрузки индекса; это не заменяет проверку первой установки на новом роутере.

## Если ядро не поддерживает NFQUEUE

Перед запуском движка служба проверяет необходимые возможности ядра в отдельной временной цепочке, не подключённой к пользовательскому трафику. Если NFQUEUE или нужные расширения недоступны, проверка завершится ошибкой **до подключения правил обработки**: NFQWS2 не запустится и не станет перехватывать соединения. Установка при этом может сообщить об ошибке запуска, а файлы пакета и веб-панель могут остаться установленными — пакет можно удалить обычной командой ниже.

Пакет не перепрошивает ASUS, не заменяет ядро и не устанавливает сторонние модули ядра. При проверке он может загрузить уже имеющиеся штатные модули прошивки. Настройки ARK обычная установка не меняет: для них есть отдельное действие с резервной копией.

Если служба запущена, но счётчики очереди остаются на нуле, это другая ситуация: поддержку правил ядро приняло, однако доставка пакетов ещё не подтверждена. Здесь полезна диагностика ARK и пути трафика. Проверка защищает от запуска без необходимых возможностей; она не даёт гарантии совместимости с любой прошивкой.

## Первый вход

Откройте в локальной сети **адрес ASUS на порту 90**. По умолчанию панель использует учётные данные администратора ASUS, если они доступны. Смена пароля в панели меняет только отдельную учётную запись WebUI, без записи в штатную учётную запись ASUS.

Проверьте WAN, режим обработки, выбранных клиентов и стратегию. Пустой список адресов в режиме включения означает отсутствие обработки этой версии IP. IPv6-обработка по умолчанию выключена; это не выключает IPv6 самого ASUS.

## Проверка

```sh
/opt/etc/init.d/S51nfqws2 status
cat /proc/net/netfilter/nfnetlink_queue
```

Панель также умеет сравнивать очередь за 10 секунд. Во время проверки откройте сервис с выбранного LAN-клиента. Рост sequence подтверждает получение пакетов движком; доступность нужного сервиса проверяйте отдельным запросом.

Для подготовки ARK используйте отдельный диалог с резервной копией. Роутер не перезагружается автоматически. Не выключайте неизвестные функции наугад.

## Необязательный DPI Detector

После установки откройте **«Поделиться»** в шапке панели и подтвердите отдельную установку DPI Detector. Затем в Entware по SSH выполните `/opt/bin/nfqws2-dpi`: настройки и проверки выбираются в оригинальном меню. Нажмите **S**, затем обновите результаты в «Поделиться». Компонент не нужен для работы NFQWS2. [Подробная инструкция](DPI-DETECTOR.md).

## Как остановить и удалить

Чтобы временно остановить обработку без удаления:

```sh
/opt/etc/init.d/S51nfqws2 stop
```

Чтобы удалить объединённый пакет с движком и веб-панелью:

```sh
/opt/bin/opkg remove nfqws2-asus
```

Штатное удаление останавливает обе службы и снимает собственные правила и задание планировщика. Если остановка службы завершится ошибкой, удаление прервётся: не используйте принудительное удаление, сначала сохраните диагностику.

Конфигурация NFQWS2, списки и журналы сохраняются для возможной повторной установки; Entware и его общие зависимости остаются на месте. Если вы отдельно применяли «Подготовку ASUS», удаление пакета **не возвращает настройки ARK**. При желании вернуть их сначала используйте восстановление из резервной копии в WebUI, пока панель ещё установлена; ручная перезагрузка может потребоваться по подсказке панели.
