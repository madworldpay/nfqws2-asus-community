# Build 97 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the confirmed MTProxy lifecycle and diagnostic fixes for every supported ASUS/Entware and OpenWrt target.

**Architecture:** Keep existing boundaries. Native MTProxy uses the packaged daemon launcher; a shared Python logging prelude covers newly generated native and Docker commands. Service checks offer two explicit DNS scopes, retain strict TLS and public-address filtering, and never mutate DNS settings or native Detector measurements.

**Tech Stack:** POSIX shell, Python, PHP, TypeScript/React, existing signed IPK/APK builders.

**Spec:** Owner's approved five-item scope in this chat; confirmed findings are retained privately outside the repository. Owner requested autonomous execution without further design questions.

## Global Constraints

- Build from public main, excluding the separate device-profile prototype.
- No credentials, learned browsing history, router identity or private reports in public source.
- Local DNS means exactly 127.0.0.1:53, not an arbitrary user URL. Never silently fall back to system DNS.
- Older requests without a scope retain system-resolver behavior; the new UI explicitly selects and labels the scope.
- No changes to existing user containers, VPN, firewall, DNS settings or working strategies.
- All 22 supported packages, signed release metadata and verified installed panel versions are separate deliverables.

## Review Focus

- MTProxy must survive the launching SSH/session exiting; stop must not signal an unrelated PID.
- Secret redaction must cover formatted log arguments, links and both native/Docker generated commands.
- Local DNS failures or poisoned/private addresses must fail honestly without fallback or relaxed TLS.
- HTTP 403/404 on a CDN root proves an HTTP response, not that the whole service is blocked or working.
- Literal mode recognition must reject expansion, duplicate definitions and ambiguous equal mode values.
