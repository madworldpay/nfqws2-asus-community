# Локальный подбор стратегии

Пользователь одобрил описанный в чате вариант и поручил реализацию и тестирование на основном ASUS и RT-AC87U OpenWrt. Дополнительных согласований для этой работы не требуется.

Кнопка в панели открывает локальную страницу подбора. Текущий профиль, стоковый и до трёх совместимых общих профилей подписанного каталога сравниваются на самом роутере. Только общий режим; раздельные профили, активный Detector, импорт/обновление исключают запуск. DNS, топология, IPv6, клиентские исключения и настройки авторизации сохраняются.

Подходы: полный перебор всех профилей слишком долог; удалённый ИИ требует передачи данных и не нужен; выбран ограниченный локальный перебор с родными JSON-проверками Detector и повторным подтверждением. Совместимость и ресурсы проверяет штатный импорт и изолированная библиотека профилей; неполные/неподтверждённые Lua не исполняются автоматически.

До воздействия сохраняются точные байты конфигурации и прежнее состояние службы. Каждая стратегия получает собственные ресурсы и AUTO. Для сравнения AUTO начинается с пустой копии, один одинаковый прогрев и два измерительных прогона тестов2,3; DNS1 проверяется один раз и не входит в рейтинг стратегий. Оригинальная история AUTO не изменяется. Фиксированы IPv4/Rustls/timeout8; параллельность2/4/10 выбирается по ресурсам до запуска и одинакова для всех сравниваемых профилей и одинаковые цели. Публикуются отдельно сырые отношения TCP/HTTP/TLS12/TLS13/QUIC и повторяемость. YouTube — обязательное отсутствие регрессий по четырём проверкам, результат не обещает воспроизведение видео на клиенте. Победитель должен улучшать минимум подтверждённых результатов и не ухудшать TLS и YouTube относительно исходного. Иначе рекомендация отсутствует.

После всех измерений всегда возвращается оригинал; «Применить лучший» — отдельное явное действие, с проверкой неизменности исходных настроек. Кандидат возвращается при неуспешном запуске. Отмена/закрытие страницы не уничтожают журнал: отмена просит независимый сторож восстановить, закрытие страницы оставляет ограниченную по времени работу на роутере. Guard отслеживает реальную PID/start/boot identity; при гибели worker восстанавливает только свои известные конфигурации. Загрузка системы восстанавливает прерванную транзакцию до запуска службы. Чужие изменения не перезаписываются; честный recovery_required с журналом.

Ограничения: один запуск, максимум3или5 готовых профилей, до3 дополнительных вариантов и общий лимит45или60мин, ограничение памяти/диска и отчётов; недоступный Detector/ABI/каталог объясняются. Применение и тестирование ASUS/Entware и OpenWrt одинаковы по смыслу. Первая установка только на два авторизованных устройства; выпуск для всех архитектур — отдельный этап после реальной проверки.


Дополнение, одобренное пользователем: цель по умолчанию «Все сервисы», либо один/несколько YouTube/Discord/Instagram. Telegram пользователь явно исключил, MTProto не меняется. Тот же полный контрольный набор native2+3; выбранные сервисы получают свои показатели по exact-domain aliases из этого набора. Selected ranking считает только их подтверждённый прирост, не допускает скрытой регрессии второго выбранного сервиса; общие TLS/YouTube ограничения сохраняются. Это проверка сетевых протоколов доменов, не автоматическое доказательство видео/голоса/ленты в приложении. Goal не может измениться посреди задания или через Apply.
