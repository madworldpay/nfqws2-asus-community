# Изменения

## Build 73

- Каталог стратегий загружается с нового HTTPS-источника, независимого от прежнего VPS. Подпись каталога и SHA256 выбранного профиля проверяются как раньше.
- Отправка профилей и диагностики переведена на новый приёмник с доставкой на почту проекта. Файлы по-прежнему отправляются только после предпросмотра и нажатия «Отправить».
- Прежний штатный адрес отправки переключается автоматически; отключённая отправка и собственные адреса владельца сохраняются.

## Build 72

- Добавлены нативные пакеты OpenWrt для ARM, ARM64, MIPS/MIPSel, MIPS64 и x86: IPK для 24.10 и APK для 25.12. [Установка и совместимость](OPENWRT.md).
- Общая панель работает со службами и сетевыми интерфейсами OpenWrt: стратегии и выбор устройств, импорт JSON и пресетов из облака, SmartDNS и диагностика.
- Нативная установка и обновление проверяют подпись, архитектуру и пакет; настройки и прежнее состояние служб сохраняются.
- Установщик одной командой выбирает вариант для ASUS/Entware или OpenWrt.
- При перезапуске службы OpenWrt правила захвата пакетов создаются заново; выбор устройств продолжает действовать.
- Исправлен обратный импорт экспортированного JSON с журналированием: скрытый путь журнала больше не принимается за недостающий файл стратегии.

## Build 71

- На роутерах без ARK панель показывает краткий положительный результат без лишних предупреждений и кнопок подготовки.
- В окне проверки объяснено, что такое ARK и почему он может мешать обработке трафика NFQWS2.

## Build 70

- Исправлен повторный импорт JSON с одинаковыми сохранёнными и активными настройками DNS.
- Подтверждённый профиль SmartDNS восстанавливается после обновления независимо от черновика.
- Исправлена совместная работа со сторонними DNS-файлами VPN; их правила сохраняются.
- Панель проверяет фактическое перенаправление DNS и сообщает, если оно изменилось.
- Обновлены стратегии.

## Build 69

- Исправлено обновление при использовании сторонних DNS-файлов, в том числе с VPN. Их настройки сохраняются.
- При незавершённом восстановлении DNS панель показывает причину и нужное действие.
- Установка одной командой распознаёт штатный статус пакета Entware.

## Build 68

- Импорт своего JSON с компьютера или пресета из облака.
- Профили провайдеров и глобальные стратегии показаны отдельно. Выбор блоков, файлов и SmartDNS, предпросмотр и отмена сохранены.
- При импорте весь состав JSON выбран сразу; ненужное можно отключить.
- Встроенные blobs движка корректно распознаются при импорте и обмене.
- Новые окна и сообщения доступны на RU и EN в обоих IPK.
- Обновлены стратегии.

## Build 67

- Обновлён пакет NFQWS2 до 1.3.2: движок 1.0.6 и комплектные Lua.
- Исправлена стандартная UDP-стратегия для новых установок.
- Настройки стратегий, SmartDNS и состояние службы сохраняются при обновлении.

## Build 66

- Исправлено обновление с Build 64/65: параметры отправки сохраняются. Установка больше не завершается ошибкой из-за замены этого файла и не оставляет NFQWS2 остановленным по этой причине.
- Исправлена повторная попытка после обрыва подготовки установки: не нужно вручную удалять её служебные файлы.
- Добавлена кнопка **«Подключить отправку»** для панелей, где канал ещё не настроен. Сведения отправляются отдельной кнопкой после предпросмотра; JSON можно сохранить без отправки.
- Собственные настройки канала, включая отключённую отправку, сохраняются.

## Build 65

- При повторной установке отсутствующий конфиг восстанавливается из актуального шаблона пакета вместе с нужными ему штатными списками. Существующие настройки и списки сохраняются.
- Ошибки прав DNS-скрипта, конфликта hook и недоступного штатного DNS показываются точнее; при отказе DNS не переключается.
- Загруженный ARK заметен в шапке и окне подготовки; запущенный процесс не считается подтверждением обхода.
- Панель объясняет, почему недоступна отправка. Публичный канал поддерживает v4; отправка требует предпросмотра и явного нажатия. Настройки канала, изменённые владельцем, сохраняются.
- Обновлены стратегии.

## Build 64

- Повторная установка после удаления сохраняет настройки и не требует старого BusyBox пакета.
- Проверка обновлений из публичного GitHub без настройки частного канала.
- Сохранена проверка подписи выпуска и SHA256 пакета.
- Старые записи уже не установленных версий Entware больше не блокируют обновление.
- Кнопка «По умолчанию» возвращает стратегии пакета; изменения применяются после сохранения.
- В общем конфиге визуально разделены основные блоки. Весь текст можно выделить и скопировать целиком.

## Build 62

- Полные лицензии и архив соответствующих исходников компонентов.
- Обновлены стратегии.
- Пояснения назначения SmartDNS и количества серверов/правил.

## Build 60 — проверяемый кандидат

- Исправлен сбой автоматического восстановления SmartDNS после обновления
  при открытой панели.
- Обычное обновление проверено на GT-BE19000AI и RT-AC87U:
  настройки и точные профили SmartDNS сохранены, перезагрузки не было.
- 186 проверок SmartDNS на каждом из трёх ABI и 15 проверок двух IPK прошли.
  Оба пакета побайтно повторены. Это не полная приёмка приложений и длительной работы.

## Реализовано в текущем WebUI

- Нумерованные этапы «С чего начать», чекап и подготовка ARK с бэкапом.
- Установка SmartDNS, выбор DoT/DoH, сайты для DNS, фиксированные ответы и возврат.
- Выборочный импорт JSON; экспорт отдельных блоков, файлов и DNS с сайтами.
- Крупные поля стратегий, визуальный перенос строк и предупреждения о кавычках.
- RU / EN и выбор темы; AUTO в новом профиле.

Актуальный пакет и соответствующие исходники всегда доступны в
[последнем выпуске](https://github.com/madworldpay/nfqws2-asus-community/releases/latest).
