# Изменения

## Документация проекта

- Уточнены назначение проекта, условия самостоятельной установки и добровольного участия в community.
- Зафиксирован принцип: бесплатный пакет и необязательная поддержка разработки.
- Добавлены планы интеграции DPI Detector с отдельным запуском и добровольным вложением результатов к диагностике.
- Эти изменения относятся к документации. Файлы Build 6, архив исходников и их контрольные суммы сохранены.

## 1.3.1-asus6 · Build 6

- Строка версий показывает основную версию, версию WebUI и затем `Build`.
- Обновлён текст благодарности после принятия диагностического отчёта почтовым сервером.
- Исправлена загрузка старого интерфейса после обновления: одинаковые размер и дата HTML больше не приводят к ошибочному ответу «не изменилось». Файлы интерфейса с хешем в имени сохраняют обычное кеширование.

## Build 4

- Предпросмотр диагностического JSON перед отправкой.
- Раздельные действия: сохранить файл, явно отправить, отменить.
- Отправка просмотренных байтов через отдельный HTTPS relay; SMTP-секрет хранится на сервере.
- Неопределённый результат отправки не вызывает автоматический повтор.

## Build 3

- Сбор безопасного диагностического отчёта текущего состояния.
- Справка рядом с кнопкой и выбор места сохранения с учётом возможностей браузера.

## Ранее

Объединённая поставка core и WebUI, отдельные пакеты ARMv7/AArch64, подготовка и проверка ARK, проверка поступления пакетов в NFQUEUE.

Обмен пользовательскими стратегиями пока находится в планах.
