# Изменения

## Build 65

- При повторной установке отсутствующий конфиг восстанавливается из актуального шаблона пакета вместе с нужными ему штатными списками. Существующие настройки и списки сохраняются.
- Ошибки прав DNS-скрипта, конфликта hook и недоступного штатного DNS показываются точнее; при отказе DNS не переключается.
- Загруженный ARK заметен в шапке и окне подготовки; запущенный процесс не считается подтверждением обхода.
- Панель объясняет, почему недоступна отправка. Публичный канал поддерживает v4; отправка требует предпросмотра и явного нажатия. Настройки канала, изменённые владельцем, сохраняются.
- Профиль «Домру» сохранён без изменения из Build 64.

## Build 64

- Повторная установка после удаления сохраняет настройки и не требует старого BusyBox пакета.
- Проверка обновлений из публичного GitHub без настройки частного канала.
- Сохранена проверка подписи выпуска и SHA256 пакета.
- Старые записи уже не установленных версий Entware больше не блокируют обновление.
- Кнопка «По умолчанию» возвращает стратегии пакета; изменения применяются после сохранения.
- В общем конфиге визуально разделены основные блоки. Весь текст можно выделить и скопировать целиком.

## Build 62

- Полные лицензии и архив соответствующих исходников компонентов.
- Готовый JSON «Домру»: стратегии, нужные файлы и SmartDNS.
- Пояснения назначения SmartDNS и количества серверов/правил.

## Build 60 — проверяемый кандидат

- Исправлен сбой автоматического восстановления SmartDNS после обновления
  при открытой панели.
- Обычное обновление проверено на GT-BE19000AI и RT-AC87U:
  настройки и точные профили SmartDNS сохранены, перезагрузки не было.
- 186 проверок SmartDNS на каждом из трёх ABI и 15 проверок двух IPK прошли.
  Оба пакета побайтно повторены. Это не полная приёмка приложений и длительной работы.

## Реализовано в текущем WebUI

- Нумерованные этапы «С чего начать», чекап и подготовка ARK с бэкапом.
- Установка SmartDNS, выбор DoT/DoH, сайты для DNS, фиксированные ответы и возврат.
- Выборочный импорт JSON; экспорт отдельных блоков, файлов и DNS с сайтами.
- Крупные поля стратегий, визуальный перенос строк и предупреждения о кавычках.
- RU / EN и выбор темы; AUTO в новом профиле.
