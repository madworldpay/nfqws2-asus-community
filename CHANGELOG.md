# Испытательная ветка после Build 20 — ещё не опубликованный IPK

- Точный профиль RT-AC87U / 384.13_10 с проверенным backend NFQUEUE. Общие проверки подбирают совместимую пару iptables/restore и фактическое направление conntrack.
- Тот же движок ARMv7 распакован из UPX; бинарник AArch64 побайтно сохранён. Модуль 87U не входит в AArch64.
- Исправлен выбор штатного пути NVRAM в WebUI старого Merlin; очередь отмечается положительно только при привязке, IDS unknown имеет пояснение.
- Краткий гайд RU/EN и свёрнутые подробности. Сначала диагностика отказа, затем остановка.
- Документированы один DoT, адреса CDN, память, USB, ограничения DPI и возврат DNS. SmartDNS отдельно; обычный путь его установки на старом opkg ещё готовится.

[Что меняется в двух пакетах](BUILD-IMPACT.md) · [SmartDNS](SMARTDNS.md)

# Build 20

- Над кнопками окна «Поделиться» теперь видна подсказка: сначала предпросмотр файлов, затем отправка. После изменения выбора или текста предпросмотр нужно повторить.
- Подсказка есть на русском и английском и остаётся видимой на узком экране.

# Build 19

- После подтверждённой отправки окно «Поделиться» закрывается, а благодарность появляется отдельно поверх страницы.
- Статус отправки и ход операции видны рядом с кнопками даже на длинной мобильной форме.
- При ошибке или неопределённом исходе окно остаётся открытым. Неопределённый результат по-прежнему запрещает повторную отправку того же набора.

# Build 18

- В справке DPI Detector объяснено различие между трафиком телефона и собственными запросами роутера.
- Под списком IPv4-устройств добавлена подсказка LAN/WAN и значок вопроса с командой поиска исходного адреса.
- Уточнены все три режима выбора устройств, смена WAN-адреса и влияние отдельных маршрутов. Подсказки доступны на русском и английском.

# Build 17

- Сообщение об успешной установке теперь называет конкретную версию и Build последнего установленного обновления.
- Убраны две повторяющиеся общие надписи. Исторический результат показывает свой выпуск даже при наличии более нового обновления.

# Build 16

- Одна кнопка «Поделиться» вместо нескольких соседних сценариев: диагностика, готовый DPI-результат, стратегия — по выбору.
- DPI Detector работает через оригинальное меню Entware. Сохранённые TXT доступны для просмотра, скачивания и удаления; в письмо попадает очищенная JSON-проекция.
- Найденные блоки стратегии и весь конфиг можно редактировать как отправляемые копии. Оператор обязателен, регион и код установки — только по отдельным галочкам.
- Диагностика дополнена пассивным контекстом DNS, DoT и известных DNS-компонентов роутера.
- Исправлены обработка ошибок записи сохранённых результатов и очистка необычно записанных файловых/секретных параметров. Короткий запрос региона ограничен отдельным процессом.
- Core, WebUI и настройки сети не обновляются автоматически: установку нового Build запускает владелец.

# Build 15

- Исправлены два сбоя обновлятора на настоящем ASUS: недоступность штатных системных команд установщику и итоговая проверка панели без необязательного расширения PHP.
- Настройки, списки и выбранное состояние службы сохраняются. Роутер перезагружать не требуется.
- Добавлены проверки обеих найденных ошибок, включая минимальный Entware PHP.

# Build 13

- Учтены автосписки, которые NFQWS2 ведёт от своего непривилегированного пользователя. Резервная копия сохраняет исходные метаданные, данные входа остаются доступны только root.
- Короткие запросы статуса панели не прерывают фоновые чтения и записи журнала обновления.
- Подготовка на настоящем ASUS проверена до стадии готовности. Установка следующего пакета остаётся отдельным действием владельца.

# Build 12

- Исправлен вызов штатного Entware flock: комплектный BusyBox больше не обязан содержать этот applet.
- Пути обновлятора следуют штатной ссылке /opt на внутреннее или внешнее хранилище.
- Исправлено чтение частного файла канала обновлений; подготовка не требует пароля, если владелец намеренно отключил вход.

Build 11 при первой установке выявил несовпадения путей и набора applet с реальным Entware. Для новой установки выбирайте Build 12. Старые файлы сохранены неизменными для истории.

# Build 11

- Обновление подписанных пакетов через WebUI, с отдельными подготовкой и подтверждением.
- Плашки основной версии, Web и Build отмечают доступные изменения.
- Резервная копия настроек, проверка пакета до остановки и сохранение состояния службы.
- Штатные настройки и полные наглядные результаты DPI Detector; очищенное добровольное вложение к диагностике.

# Изменения

## 1.3.1-asus6 · Build 10

- Остановка проверки пользователем отображается как «Остановлено», отдельно от неожиданного прерывания.
- Уже завершённые группы остаются доступны для просмотра и сохранения после остановки.

## 1.3.1-asus6 · Build 9

- DPI-подсистема учитывает штатную ссылку `/opt` на установленный Entware. Защита собственных каталогов от посторонних ссылок сохранена.
- Исправление проверено на ASUS со штатным расположением Entware.

## 1.3.1-asus6 · Build 8

- Устранена гонка между завершением одной группы DPI и созданием таймера следующей. Время каждой группы остаётся ограниченным и при немедленном последовательном запуске.
- Уточнена инструкция скачивания из приватного репозитория и установки локального IPK.

## 1.3.1-asus6 · Build 7

- Необязательная установка закреплённого официального DPI Detector и отдельный запуск всех семи групп проверок.
- Ограниченный профиль, независимое ограничение времени, остановка, частичные результаты, просмотр и сохранение очищенного JSON.
- Добровольное DPI-вложение к диагностике: два точных предпросмотра, одна явная отправка; серверная поддержка включается отдельно.
- Спокойное отображение отсутствующего ARK и положительные отметки там, где состояние действительно благоприятно для работы.
- Внизу панели — благодарности и ссылки на исходные проекты.
- Исправлены аварийное завершение дочерней пробы, срок хранения, полное удаление результатов и очистка прерванной установки.

## Документация проекта

- Уточнены назначение проекта, условия самостоятельной установки и добровольного участия в community.
- Зафиксирован принцип: бесплатный пакет и необязательная поддержка разработки.
- Добавлены планы интеграции DPI Detector с отдельным запуском и добровольным вложением результатов к диагностике.
- Эти изменения относятся к документации. Файлы Build 6, архив исходников и их контрольные суммы сохранены.

## 1.3.1-asus6 · Build 6

- Строка версий показывает основную версию, версию WebUI и затем `Build`.
- Обновлён текст благодарности после принятия диагностического отчёта почтовым сервером.
- Исправлена загрузка старого интерфейса после обновления: одинаковые размер и дата HTML больше не приводят к ошибочному ответу «не изменилось». Файлы интерфейса с хешем в имени сохраняют обычное кеширование.

## Build 4

- Предпросмотр диагностического JSON перед отправкой.
- Раздельные действия: сохранить файл, явно отправить, отменить.
- Отправка просмотренных байтов через отдельный HTTPS relay; SMTP-секрет хранится на сервере.
- Неопределённый результат отправки не вызывает автоматический повтор.

## Build 3

- Сбор безопасного диагностического отчёта текущего состояния.
- Справка рядом с кнопкой и выбор места сохранения с учётом возможностей браузера.
