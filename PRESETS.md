# Каталог пресетов

> **Каталог стратегий перенесён на новый источник.** Для импорта и отправки профилей используйте актуальный пакет. Уже применённые стратегии продолжают работать; свой JSON также можно открыть через «С компьютера (JSON)».

Каталог используется в панелях ASUS/Entware и OpenWrt. Поддерживаемые пути ресурсов адаптируются при импорте; выбор и предпросмотр сохраняются.

В панели нажмите **импорт → «Из облака»**. Каталог содержит два раздела:

- **Профили провайдеров** — настройки для конкретного подключения: например,
  `DOM.RU-TulskayOblast` и `Rostelekom-DalniyVostok`.
- **Глобальные стратегии** — варианты для подбора под свою сеть. Это название
  раздела, а не обещание одинакового результата у всех провайдеров.

Выберите профиль: его блоки, списки, blobs и SmartDNS уже отмечены так, как их
передал автор. Можно снять ненужное. В **«Предпросмотре»** сравните изменения,
затем нажмите **«Сохранить выбранное»** и перезапустите NFQWS2.
Загрузка пресета сама ничего не включает. DNS сохраняется в черновик SmartDNS
и подключается отдельно через его мастер.

Свой JSON открывается через **«С компьютера (JSON)»**. Этот способ доступен
и при недоступном каталоге. Последний импорт можно отменить, пока его данные
не менялись отдельно.

Проверяйте результат с нужного устройства: загрузку сайта, воспроизведение и
перемотку видео, голосовое соединение. Если нашли удачный вариант, **поделитесь
стратегией и результатом проверки** — это помогает улучшать каталог.
Откройте **«Экспорт / поделиться»**, отметьте стратегию и её файлы, укажите
провайдера и результат, проверьте предпросмотр и нажмите **«Отправить»**.

## Загрузка и обмен

Каталог и файлы профилей загружаются по HTTPS. Панель проверяет подпись каталога,
размер и SHA256 выбранного JSON, затем показывает обычный предпросмотр импорта.
Профили, отправленные через «Экспорт / поделиться», приходят на почту проекта
для ручного разбора. Они не попадают в каталог автоматически. Административные
панели роутера не являются частью публичного источника стратегий.

The catalog and profile files use HTTPS. The panel verifies the catalog signature,
file size and SHA256 before showing the import preview. Shared profiles reach the
project mailbox for manual review and are never published automatically. Router
administration panels are separate from the public strategy source.
