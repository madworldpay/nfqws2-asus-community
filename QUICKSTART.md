# Быстрый старт

## ASUSWRT-Merlin / Entware

Для роутера с установленной ASUSWRT-Merlin.

### 1. Установить

**Если Entware уже работает в `/opt`, переходите к команде установки.**
На свежей ASUSWRT-Merlin сначала подготовьте Entware:

1. Подключите USB-накопитель с Linux-файловой системой — обычно ext4; ext2/ext3 также подходят. Перед форматированием сохраните нужные файлы с накопителя.
2. Включите SSH для локальной сети в **«Администрирование → Система»** и подключитесь к роутеру с учётной записью администратора ASUS.
3. В SSH выполните `amtm`, выберите `ep` и дождитесь завершения установки Entware.
4. Нажмите `e`, затем Enter, чтобы выйти из меню `amtm` обратно в ту же SSH-консоль. Проверьте Entware командой `/opt/bin/opkg print-architecture`.

Теперь в этой же SSH-консоли вставьте команду целиком:

```sh
(
  set -e
  umask 077
  nfqws_dir=/tmp/nfqws2-install.$$
  mkdir "$nfqws_dir"
  trap 'rm -rf "$nfqws_dir"' 0
  curl -fL --connect-timeout 10 --max-time 60 \
    https://raw.githubusercontent.com/madworldpay/nfqws2-asus-community/main/install.sh \
    -o "$nfqws_dir/install.sh"
  sh "$nfqws_dir/install.sh"
)
```

Она выберет актуальный IPK по архитектуре Entware, проверит SHA256 и установит
пакет с сохранением настроек. При первой установке обработка остаётся выключенной;
при обновлении сохраняется прежнее состояние. В конце появится ссылка на панель.

Команда использует штатный `curl` Merlin.

**Ручная установка:** вместо команды выше можно скачать IPK и передать его
через WinSCP/SCP или скопировать в сетевую папку USB по Samba.
[Пошаговый перенос и установка, включая Проводник Windows](MANUAL-INSTALL.md).

### 2. Настроить

**Вход в панель ASUS:** используйте логин и пароль администратора роутера.
Если панель не может прочитать системные учётные данные ASUS, автоматически
включается резервный вход: **логин `root`, пароль `asus`**.
Ранее заданный отдельный пароль панели сохраняется при обновлении — используйте его.
Кнопка **«Сменить пароль»** позволяет задать свой пароль панели.

1. Откройте `http://IP-роутера:90`.
2. **«Проверка ARK»**: если ARK отсутствует, подготовка не требуется — переходите дальше. При загруженном модуле выполните подготовку с бэкапом и ручной перезагрузкой. Если модуль не загружен, этот шаг не нужен.
3. Оставьте автоматический выбор WAN или укажите интерфейс, выберите устройства и стратегию либо импортируйте JSON или пресет из облака. Нажмите **«Сохранить»**. Штатный конфиг использует AUTO.
4. Для правил «сайт → DNS» установите отдельную утилиту: **SmartDNS → установить → выбрать DNS и сайты → проверить профиль → подключить → подтвердить**.
5. Запустите или перезапустите NFQWS2. Проверьте нужные сервисы с выбранного клиента.

**«С чего начать»** показывает готовые и незавершённые этапы. Подробности полей — в **«?»**.
Рабочий профиль можно передать через **«Экспорт / поделиться» → «Предпросмотр» → «Отправить»**.

### 3. Если нужен возврат

Сначала сохраните диагностику. Для SmartDNS нажмите **«Вернуть прежний DNS»**;
для остановки обработки выполните:

```sh
/opt/etc/init.d/S51nfqws2 stop
```

## OpenWrt

Для роутера с установленной OpenWrt. Entware не требуется.
Войдите по SSH в роутер от `root` и выполните:

```sh
(
  umask 077
  nfqws_dir=/tmp/nfqws2-install.$$
  mkdir "$nfqws_dir" || exit 1
  trap 'rm -rf "$nfqws_dir"' 0
  nfqws_url=https://raw.githubusercontent.com/madworldpay/nfqws2-asus-community/main/install.sh
  { curl -fL --connect-timeout 10 --max-time 60 "$nfqws_url" -o "$nfqws_dir/install.sh" || uclient-fetch -T 20 -O "$nfqws_dir/install.sh" "$nfqws_url"; } &&
  sh "$nfqws_dir/install.sh"
)
```

Установщик сам выберет нативный пакет по версии и архитектуре OpenWrt,
проверит подпись и SHA256, затем покажет адрес панели.

Для ручного выбора файла используйте [порядок для OpenWrt](OPENWRT.md#установить-пакет-вручную).

1. Откройте `http://IP-роутера:90`. Для входа используется учётная запись `root` OpenWrt; пароль панели можно сменить отдельно.
2. Оставьте автоматический WAN. Выберите устройства и стратегию либо импортируйте профиль из облака. Проверьте предпросмотр, сохраните настройки и запустите NFQWS2.
3. Если профиль содержит DNS, откройте SmartDNS: **«Установить» → «Проверить профиль» → «Подключить» → подтвердить результат**.
4. Проверьте нужные сервисы с выбранного устройства. Если панель предупреждает об ускорении трафика, выполните её подсказки по flow offloading.

Для выбранных устройств закрепите IP в **LuCI → Сеть → DHCP и DNS → Статические аренды**.
Для остановки используйте кнопку панели или `/etc/init.d/nfqws2-native stop`;
для возврата DNS — **«Вернуть прежний DNS»** в SmartDNS.

[Совместимость устройств и особенности OpenWrt](OPENWRT.md).
