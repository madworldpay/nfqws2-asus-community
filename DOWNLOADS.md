# Пакеты Build 20

Основная версия **1.3.1-asus6**, WebUI **0.1.4**, **Build 20**. Два объединённых пакета: каждый содержит core и веб-панель.

| Основной ABI Entware | Файл |
| --- | --- |
| `aarch64-3.10` | [AArch64 IPK](nfqws2-asus_1.3.1-asus6+b20_aarch64-3.10.ipk) |
| `armv7-2.6` / `armv7-3.2` | [ARMv7 IPK](nfqws2-asus_1.3.1-asus6+b20_armv7.ipk) |

[Контрольные суммы](SHA256SUMS) · [Исходники](nfqws2-asus-source-b20.zip) · [Установка](INSTALL.md) · [Совместимость](COMPATIBILITY.md) · [Памятка](USAGE.md)

Пакеты экспериментальные. Совпадение архитектуры не подтверждает работу NFQUEUE конкретного ядра. Репозиторий пока приватный: ссылки на файлы требуют доступа к нему; команды публичного однострочного установщика ещё нет.

Скачивание и использование пакетов бесплатные. Поддержка разработки добровольная. В памятке описаны назначение проекта и условия самостоятельной установки; лицензии компонентов сохраняются.

Build 6 сохранён в истории файлов и остаётся в репозитории для сравнения. В Build 20 добавлено единое окно «Поделиться»; оригинальный DPI Detector устанавливается отдельно по согласию и запускается в Entware.

## Испытательная ветка после Build 20

Поддержка точного 87U, уточнённые статусы и краткий гайд проверяются в локальных пакетах. Они не подменяют перечисленные выше файлы Build 20. [Изменения](BUILD-IMPACT.md) и [границы испытаний](SMARTDNS.md) опубликованы отдельно; ссылки на новый IPK появятся после подготовки выпуска.
